# Страницы лабораторных работ (lab.html)

Каждая лабораторная работа (кроме курсовой) получает интерактивную страницу
`lab.html` рядом с `README.md`. Страница строится движком `assets/lab.js`
из конфига `window.LAB` — HTML содержит только конфиг и два тега `<script>`.

## Каркас страницы

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>01 · Название — лабораторная работа</title>
  <link rel="stylesheet" href="{base}assets/lab.css">
</head>
<body>
<script src="{base}assets/gens/нужный-генератор.js"></script>  <!-- опционально, ДО lab.js -->
<script>
window.LAB = { ...конфиг... };
</script>
<script src="{base}assets/lab.js"></script>
</body>
</html>
```

`base` — путь к корню репозитория: `'../../../'` для работ 1 семестра
(`1семестр/часть/работа/`), `'../../'` для 2 семестра (`2семестр/работа/`).

## Конфиг window.LAB

| Поле | Тип | Смысл |
|---|---|---|
| `base` | строка | путь к корню, как в `<link>` |
| `num`, `title`, `algo` | строка | номер, название, чип с именем алгоритма |
| `crumb` | строка | хлебные крошки в шапке («1 семестр · Раздел») |
| `lead` | строка (HTML) | подзаголовок под заголовком |
| `task` | массив строк (HTML) | пункты задания — рисуются на «листочке» |
| `chips` | `[{t, cls}]` | статические чипы (сложность, устойчивость); `cls`: `''` \| `'m'` \| `'plain'` |
| `hint` | строка | подсказка под полем ввода |
| `inputs` | `[{id,label,value,example,placeholder}]` | поля ввода (example — кнопка «Пример») |
| `kind` | `'numbers'`\|`'letters'` | режим разбора ввода (по умолчанию авто) |
| `max` | число | максимум элементов (по умолчанию 16) |
| `pseudo` | `[[строка, теги]]` | псевдокод, вторая часть — теги строк через пробел |
| `file` | `{name, url, lines: [[строка, теги]]}` | вкладка «Файл» |
| `details` | `[{s, h}]` | сворачиваемые блоки (трудоёмкость, проверка…) |
| `links` | `[{href, label}]` | пиллы-ссылки в шапке |
| `dockTitle`, `dockDesc` | строка | заголовок «листочка» |
| `steps(ctx)` | функция | **обязательно**: возвращает массив шагов |
| `noInit` | bool | если true — страница сама вызывает `Lab.init()` |

## Разбор ввода

Без `parse` ввод разбирается автоматически: числа через пробел/запятую → массив
чисел, иначе — массив символов (переводятся в верхний регистр). `parse(vals)`
позволяет переопределить (например, `{arr, x}` для поиска или `{keys, m}` для
хеширования) и возвращать произвольный контекст для `steps`.

## API для генераторов шагов (`window.Lab`, глобальный `Lab`)

Подключается в `lab.js`; собственные генераторы кладутся в `window.LabGen`
в файле `assets/gens/*.js`, подключаемом **до** `lab.js`:

```js
(function () {
  var G = window.LabGen = window.LabGen || {};
  G.myAlgo = function (data) { /* ... */ return steps; };
})();
```

### Помощники

- `Lab.range(a, b)` → `[a, a+1, …, b]`
- `Lab.esc(s)` — HTML-эскейп
- `Lab.cells(vals, {hl, box, done, dim, under, ptrs, idx})` — строка ячеек массива.
  `hl` — подсветка сравнения, `box` — рамка текущего, `done` — готовая часть,
  `dim` — призрачная, `under` — подчёркивание, `ptrs: {3: 'j'}` — метки над ячейками,
  `idx` — номера снизу.
- `Lab.rows([{label, vals, …}, {note: 'текст'}], o)` — несколько строк + вставки-заметки
- `Lab.list(vals, {label, ptrs, hl, done, nil})` — связный список со стрелками → и NIL
- `Lab.tree(root, { })` — SVG-дерево. Узел: `{v, l, r, hl, edge, lab}`;
  `hl`: `'root'` \| `'ok'` \| `'warn'` \| `'dim'`; `edge: 'hl'` — выделить ребро к узлу;
  `lab` — подпись под узлом (высота, баланс).
- `Lab.pair(a, b, capA, capB)` — два дерева рядом
- `Lab.htable(slots, {mode:'chain'|'open', hl:[i], ok:[i]})` — хеш-таблица;
  `slots` — массив массивов элементов `{v, s}` (пусто = `[]`)
- `Lab.note('текст')` — подпись-заметка
- `Lab.mkCount()`, `Lab.cnt(state, dC, dM)`, `Lab.swap(a, i, j)`, `Lab.finish(a, st, st2, name)`

### Формат шага

```js
{
  title: 'Сравнение «F» и «A»',        // заголовок шага
  text:  'HTML-описание с <b> и <code>',// текст под заголовком
  tags:  ['scan', 'cmp'],               // теги подсветки строк кода
  ftags: [...],                         // если для вкладки «Файл» нужны другие теги
  stage: Lab.cells(...) | Lab.tree(...) | 'произвольный HTML',
  cap:   'подпись под сценой',
  C: st.C, M: st.M                      // счётчики для чипов
}
```

Теги шага (`tags`) сверяются с тегами строк в `pseudo` и `file.lines` —
подсвечиваются те строки, у которых есть общий тег. Это связывает шаги и код:
строки псевдокода и исходника размечены одинаковыми тегами.

### Готовые генераторы (assets/lab.js)

`select` (opt `{improved:true}`), `bubble`, `shaker`, `insert`, `shell`, `heap`,
`quick`, `indexArrays`, `binarySearch` (`{arr, x}`), `hashChaining` (`{keys, m}`),
`hashOpen` (`{keys, m}`).

## Требования к контенту

- **task** — реальные пункты задания из README работы (сокращённо, HTML допустим).
- **pseudo** — псевдокод из README работы, размеченный тегами.
- **file.lines** — ключевые строки настоящего исходника (функция алгоритма),
  размеченные теми же тегами, что шаги.
- Шаги должны честно отражать алгоритм: счётчики C/M там, где их считает программа.
- Каждая страница открывается по ссылке из `index.html` и из README работы
  (в README добавляется строка со ссылкой на `lab.html`).
