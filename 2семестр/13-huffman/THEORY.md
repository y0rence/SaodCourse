# Код Хаффмана

Код Хаффмана — оптимальный побуквенный префиксный код: он даёт минимальную среднюю длину кодового слова среди всех префиксных кодов для данного распределения вероятностей. Идея метода — многократно объединять два наименее вероятных символа в один узел, пока не останется два, а затем обратным проходом достраивать кодовые слова.

## Основные формулы

| Величина | Формула |
|---|---|
| Вероятность символа | `P_i = n_i / N`, где `n_i` — частота символа, `N` — общее число символов |
| Энтропия | `H = −Σ P_i · log₂ P_i` |
| Средняя длина кодового слова | `Lcp = Σ P_i · L_i` |
| Избыточность кода | `r = Lcp − H` |
| Неравенство Крафта | `Σ 2^(−L_i) ≤ 1` |

Код называется **префиксным**, если ни одно кодовое слово не является началом другого. Для оптимального кода выполняется `H ≤ Lcp < H + 1`, поэтому избыточность не превышает единицы.

## Алгоритм построения

1. Символы сортируют по убыванию вероятностей: `p1 ≥ p2 ≥ … ≥ pn`.
2. Пока в списке не останется два элемента, берут два наименьших значения `P[n−1]` и `P[n]`, складывают их `q := P[n−1] + P[n]` и вставляют сумму в список с сохранением порядка (функция `Up`).
3. Когда остаются два символа, им приписываются коды `0` и `1`.
4. Обратным проходом (процедура `Down`) достраиваются кодовые слова: если слитый узел получил бит `b`, то его два потомка получают `b0` и `b1`.

Псевдокод пособия: `Huffman(n,P)` при `n = 2` задаёт коды `0` и `1`, иначе вычисляет `q := P[n−1] + P[n]`, вызывает `Up(n,q)`, рекурсивно обрабатывает `n−1` символов и завершается вызовом `Down(n,j)`.

## Гарантии и свойства

- оптимальный: средняя длина минимальна среди всех префиксных кодов;
- код префиксный, неравенство Крафта выполняется (для полного дерева сумма равна единице);
- у двух самых редких символов длины отличаются не более чем на единицу.

## Пример из пособия

При вероятностях `0.36, 0.18, 0.18, 0.12, 0.09, 0.07` получаются длины `1, 3, 3, 3, 4, 4` (таблица 10 пособия):

```text
Lcp = 0.36·1 + 0.18·3 + 0.18·3 + 0.12·3 + 0.09·4 + 0.07·4 = 2.44,  H = 2.37.
```

При равных вероятностях порядок слитых символов может отличаться от таблицы пособия, но средняя длина от этого не меняется.

## Связь с программой

Реализация — `Huffman.cpp` (задания 2–4), текст `proizvedenie_11kb.txt` (57 букв, `N = 4489`): неравенство Крафта `1.000000 ≤ 1` выполняется, энтропия `H = 4.780912`, средняя длина `Lcp = 4.809089`, избыточность `r = 0.028177`. Сравнение средних длин: Хаффман `4.809089`, Фано `4.812876`, Шеннон `5.379372` — код Хаффмана короче всех, что подтверждает его оптимальность. Подробности — в [README](README.md).
