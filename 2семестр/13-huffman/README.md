# 13. Код Хаффмана (задания 2–4)

> **Интерактивная страница:** [lab.html](lab.html) — пошаговый проигрыватель с подсветкой кода (псевдокод ↔ исходный файл).

[Теория](THEORY.md)

Оптимальный побуквенный код Хаффмана по псевдокоду пособия СиАОД
(п. 16.4): `Huffman(n,P)` с функцией `Up` (поиск и вставка суммы)
и процедурой `Down` (достраивание кодовых слов).

## Файлы

| Файл | Назначение |
|---|---|
| `Huffman.cpp` | программа (задания 2, 3 и 4) |
| `proizvedenie_11kb.txt` | текст произведения, 11299 байт (≥ 10 КБ по условию) |

## Задания

1. **Задание 2** — строит оптимальный код Хаффмана по псевдокоду
   `Huffman(n,P)` / `Up(n,q)` / `Down(n,j)` и выводит таблицу:
   Символ | Вероятность символа | Кодовое слово | Длина кодового слова.
2. **Задание 3** — проверяет неравенство Крафта, считает энтропию `H`,
   среднюю длину `Lср` и избыточность `r = Lср − H`, выводит таблицу
   (Неравенство Крафта | Энтропия исходного текста | Средняя длина
   кодового слова | Избыточность кода Хаффмана) и **сравнивает среднюю
   длину с ранее построенными кодами Шеннона и Фано** (Шеннон считается
   по формуле `L_i = ⌈−log2 P_i⌉`, Фано строится заново функциями
   `Med` и `Fano` — те же алгоритмы, что в работах 11 (Шеннон) и 12 (Фано)).
3. **Задание 4** — кодирует первые 100 символов текста кодом Хаффмана,
   выводит закодированную последовательность, её длину и оценивает
   коэффициент сжатия относительно равномерного кода и UTF-8.

## Сборка и запуск

```sh
clang++ -o Huffman Huffman.cpp && ./Huffman
```

Альтернативно:

```sh
g++ -o Huffman Huffman.cpp
./Huffman                       # файл по умолчанию proizvedenie_11kb.txt
./Huffman другой_файл.txt       # можно указать свой файл
```

## Результаты на тексте из 11 КБ (N = 4489 символов, 57 букв)

Задание 3 — оценка кода Хаффмана:

| Неравенство Крафта | Энтропия H | Средняя длина Lср | Избыточность r |
|---|---|---|---|
| 1.000000 ≤ 1, выполняется | 4.780912 | 4.809089 | 0.028177 |

Сравнение средних длин кодовых слов:

| Код | Средняя длина кодового слова |
|---|---|
| Хаффмана | **4.809089** |
| Шеннона | 5.379372 |
| Фано | 4.812876 |

Код Хаффмана — оптимальный: его средняя длина не больше, чем у кодов
Фано и Шеннона, и близка к энтропии (избыточность ≈ 0.028 бит/символ).

Задание 4 — кодирование первых 100 символов:

- длина закодированной последовательности: **521 бит** (5.21 бит/символ);
- при равномерном коде (6 бит/символ): 600 бит → коэффициент сжатия **1.152**;
- в UTF-8 (16 бит/символ): 1600 бит → коэффициент сжатия **3.071**.

## Проверка по примеру из пособия (Таблица 10)

При вероятностях 0.36, 0.18, 0.18, 0.12, 0.09, 0.07 программа даёт
среднюю длину **2.440000** — точно как в пособии (и 2.92 для кода
Шеннона, и 2.44 для кода Фано — совпадает с Таблицами 11 и 12).

Примечание: при равных вероятностях (0.36 = 0.36) псевдокод `Up`
использует сравнение `P[i-1] <= q`, поэтому при равенстве сумма
встаёт перед равным элементом — из-за этого отдельные кодовые слова
могут отличаться от Таблицы 10 (там a1 = «1», здесь a1 = «00»).
Средняя длина от этого не меняется: она равна 2.44 в обоих случаях,
код остаётся оптимальным и префиксным (Крафт = 1).
