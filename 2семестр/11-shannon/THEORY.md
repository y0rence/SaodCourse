# Код Шеннона

Код Шеннона — почти оптимальный побуквенный префиксный код. Длина кодового слова задаётся округлением вверх двоичного логарифма вероятности символа, а сами биты берутся из двоичной записи накопленной суммы вероятностей предыдущих символов. Частый символ получает короткое кодовое слово, поэтому средняя длина близка к энтропии источника.

## Основные формулы

| Величина | Формула |
|---|---|
| Вероятность символа | `P_i = n_i / N`, где `n_i` — частота символа, `N` — общее число символов |
| Энтропия | `H = −Σ P_i · log₂ P_i` |
| Средняя длина кодового слова | `Lcp = Σ P_i · L_i` |
| Избыточность кода | `r = Lcp − H` |
| Неравенство Крафта | `Σ 2^(−L_i) ≤ 1` |

Код называется **префиксным**, если ни одно кодовое слово не является началом другого. Для префиксного кода выполняется неравенство Крафта, и сообщение декодируется однозначно: биты читаются слева направо до первого полного кодового слова.

## Алгоритм построения

1. Символы сортируют по убыванию вероятностей: `p1 ≥ p2 ≥ … ≥ pn`.
2. Длину кодового слова определяют из условия `1 / 2^L_i ≤ p_i < 1 / 2^(L_i − 1)`, то есть `L_i = ⌈−log₂ p_i⌉`.
3. Вычисляют накопленные суммы `Q_0 = 0`, `Q_i = p1 + … + p_i`.
4. Разряды `i`-го кодового слова извлекают из `Q_{i−1}`: значение умножают на 2, бит равен целой части, вычисленная единица вычитается.

## Гарантии и свойства

- код префиксный, поэтому неравенство Крафта выполняется;
- средняя длина удовлетворяет неравенству `Lcp < H + 1`, отсюда избыточность `0 ≤ r < 1`;
- код почти оптимальный: он проигрывает оптимальному коду Хаффмана не более чем на один бит на символ.

## Пример из пособия

Пусть вероятности равны `0.36, 0.18, 0.18, 0.12, 0.09, 0.07` (таблица 11 пособия). Энтропия источника `H = 2.37`, длины кодовых слов равны `2, 3, 3, 4, 4, 4`, поэтому

```text
Lcp = 0.36·2 + (0.18 + 0.18)·3 + (0.12 + 0.09 + 0.07)·4 = 2.92 < 2.37 + 1 = H + 1.
```

Кодовые слова `00`, `010`, `100`, `1011`, `1101`, `1110` префиксны: ни одно не является началом другого.

## Связь с программой

Реализация — `Shennon.cpp` (задания 1–4), текст `proizvedenie_11kb.txt` (57 букв, `N = 4489`): программа выводит частотный словарь и таблицу кодов, проверяет неравенство Крафта, считает `H`, `Lcp` и `r = Lcp − H`, кодирует первые 100 символов. Средняя длина кода Шеннона на этом тексте равна `5.379372` — заметно больше, чем у кодов Фано и Хаффмана, что иллюстрирует почти оптимальность метода. Подробности — в [README](README.md).
