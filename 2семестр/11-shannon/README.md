# 11. Код Шеннона

> **Интерактивная страница:** [lab.html](lab.html) — пошаговый проигрыватель с подсветкой кода (псевдокод ↔ исходный файл).

Побуквенный статический код Шеннона для русского текста: частоты символов, вероятности, длины кодовых слов и сами коды, проверка неравенства Крафта, энтропия, средняя длина и избыточность, кодирование первых 100 символов.

## Задание

1. Для 10 первых неповторяющихся символов ФИО студента построить вручную код Шеннона. Вероятности символов оценить по всей ФИО с точностью до двух знаков после запятой. Проверить неравенство Крафта, вычислить среднюю длину кодового слова и сравнить её с энтропией.
2. Реализовать алгоритм построения побуквенного статического кода Шеннона для текста на русском языке. Для оценки вероятностей использовать файл не менее 10 КБ и вывести на экран кодовую таблицу: символ, вероятность, кодовое слово, длина кодового слова.
3. Для построенного кода проверить неравенство Крафта, сравнить среднюю длину кодового слова с энтропией исходного файла, определить избыточность кода.
4. Закодировать русский текст из 100 символов, вывести закодированную последовательность, её длину и оценить коэффициент сжатия.

## Сборка и запуск

Из папки работы:

```bash
g++ -std=c++17 -O2 -Wall -Wextra Shennon.cpp -o Shennon
./Shennon
```

Программа читает `proizvedenie_11kb.txt` (кодировка UTF-8) и печатает частотный словарь, таблицу кодов Шеннона, блок «Задание 3» (сумма вероятностей, Крафт, энтропия, средняя длина, избыточность) и «Задание 4» (закодированная строка первых 100 символов и коэффициент сжатия). Другой файл передаётся аргументом:

```bash
./Shennon proizvedenie_2kb.txt
```

## Как проверить результат

Соберите бинарник с именем `Shennon` (команда выше) и выполните из папки работы:

```bash
python3 verify.py
```

Скрипт прогоняет три текста и печатает `PASS`/`FAIL` по каждой проверке: сумма частот равна `N`, сумма вероятностей равна 1, `N` совпадает с числом кириллических букв файла, длина `L_i = ⌈−log2 P_i⌉`, Крафт не превышает 1, `H`, `Lcp` и `R` совпадают с выводом программы, `Lcp < H + 1`, избыточность в диапазоне `0 ≤ R < 1`, коды префиксные и уникальные, а обратное декодирование первых 100 символов возвращает исходный текст. Итог — строка `ВСЁ ХОРОШО, ошибок: 0`.

## Методика (пособие, п. 16.5)

- `P_i = n_i / N` — вероятность символа, кодовые слова строятся по убыванию `P`.
- Длина кода: `1/2^L ≤ P_i < 1/2^(L−1)`, то есть `L_i = ⌈−log2 P_i⌉`; отсюда `Lcp < H + 1`.
- Разряды кода берутся из накопленной вероятности предыдущих символов: `X = Q_{i−1}`, затем `X ← 2X`, бит — целая часть `X`.
- Избыточность `R = Lcp − H`; для кода Шеннона `0 ≤ R < 1`, поэтому код почти оптимален.
- Коды префиксные: ни один не является началом другого, поэтому текст декодируется однозначно.
