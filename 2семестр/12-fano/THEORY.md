# Код Фано

Код Фано — метод построения префиксного почти оптимального кода. Отсортированный по убыванию вероятностей список символов рекурсивно делится на две части с как можно более близкими суммами вероятностей: символам первой части добавляется бит `0`, символам второй — бит `1`. Деление продолжается, пока каждый кусок не будет содержать один символ.

## Основные формулы

| Величина | Формула |
|---|---|
| Вероятность символа | `P_i = n_i / N`, где `n_i` — частота символа, `N` — общее число символов |
| Энтропия | `H = −Σ P_i · log₂ P_i` |
| Средняя длина кодового слова | `Lcp = Σ P_i · L_i` |
| Избыточность кода | `r = Lcp − H` |
| Неравенство Крафта | `Σ 2^(−L_i) ≤ 1` |

Код называется **префиксным**, если ни одно кодовое слово не является началом другого. Для префиксного кода выполняется неравенство Крафта, и текст декодируется однозначно.

## Алгоритм построения

1. Символы сортируют по убыванию вероятностей: `p1 ≥ p2 ≥ … ≥ pn`.
2. Для текущего отрезка `[L, R]` функция `Med(L, R)` находит медиану `m` — такой индекс, при котором разность сумм `|Σ_(i=L..m) p_i − Σ_(i=m+1..R) p_i|` минимальна, то есть части делятся почти пополам.
3. Символам `L..m` добавляют бит `0`, символам `m+1..R` — бит `1`; длины кодовых слов увеличиваются на единицу.
4. Рекурсивно обрабатывают отрезки `[L, m]` и `[m+1, R]`, пока в отрезке не останется один символ — ему достаётся готовое кодовое слово.

## Гарантии и свойства

- код префиксный, поэтому неравенство Крафта выполняется (для полного дерева сумма равна единице);
- почти оптимальный: `Lcp < H + 1`, избыточность `r < 1`;
- средняя длина может превышать оптимальную (код Хаффмана), но не более чем на один бит на символ.

## Пример из пособия

При вероятностях `0.36, 0.18, 0.18, 0.12, 0.09, 0.07` метод даёт коды `00, 01, 10, 110, 1110, 1111` с длинами `2, 2, 2, 3, 4, 4` (таблица 12 пособия):

```text
Lcp = 0.36·2 + 0.18·2 + 0.18·2 + 0.12·3 + 0.09·4 + 0.07·4 = 2.44 < 2.37 + 1 = H + 1.
```

## Связь с программой

Реализация — `Fano.cpp` (задания 2–4), текст `proizvedenie_11kb.txt` (57 букв, `N = 4489`): неравенство Крафта `1.000000 ≤ 1` выполняется, энтропия `H = 4.780912`, средняя длина `Lcp = 4.812876`, избыточность `r = 0.031964`. Задание 4 строит вариант кода с медианой из алгоритма А2: `Lcp = 4.830029`, `r = 0.049117`. Оба кода префиксные и почти оптимальные. Подробности — в [README](README.md).
