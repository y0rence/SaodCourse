# 12. Код Фано (задания 2–4)

Побуквенный статический код Фано по псевдокоду пособия СиАОД (п. 16.5),
а также вариант кода с медианой из алгоритма А2 (п. 14.3).

## Файлы

| Файл | Назначение |
|---|---|
| `Fano.cpp` | программа (задания 2, 3 и 4) |
| `proizvedenie_11kb.txt` | текст произведения, 11299 байт (≥ 10 КБ по условию) |

## Задания

1. **Задание 2** — строит код Фано по псевдокоду `Fano(L,R,k)` с функцией
   медианы `Med(L,R)` и выводит таблицу: Символ | Вероятность символа |
   Кодовое слово | Длина кодового слова.
2. **Задание 3** — для построенного кода проверяет неравенство Крафта,
   считает энтропию `H`, среднюю длину `Lср` и избыточность `r = Lср − H`
   и выводит таблицу: Неравенство Крафта | Энтропия исходного текста |
   Средняя длина кодового слова | Избыточность кода Фано.
3. **Задание 4** — строит код Фано заново, вычисляя медиану функцией
   `MedA2` из алгоритма А2, и выводит таблицы п.2 и п.3 для этого варианта.

## Сборка и запуск

```sh
clang++ -o Fano Fano.cpp && ./Fano
```

Альтернативно (компилятор g++ и запуск отдельно):

```sh
g++ -o Fano Fano.cpp
./Fano                       # файл по умолчанию proizvedenie_11kb.txt
./Fano другой_файл.txt       # можно указать свой файл
```

## Результаты на тексте из 11 КБ (N = 4489 символов, 57 букв)

| Вариант | Неравенство Крафта | Энтропия H | Средняя длина Lср | Избыточность r |
|---|---|---|---|---|
| Задание 2 (`Med`) | 1.000000 ≤ 1, выполняется | 4.780912 | 4.812876 | 0.031964 |
| Задание 4 (`MedA2`) | 1.000000 ≤ 1, выполняется | 4.780912 | 4.830029 | 0.049117 |

Оба кода префиксные (неравенство Крафта выполняется), средняя длина
близка к энтропии, избыточность меньше 1 бита на символ.

## Проверка по примеру из пособия (Таблица 12)

При вероятностях 0.36, 0.18, 0.18, 0.12, 0.09, 0.07 программа выдаёт
коды `00, 01, 10, 110, 1110, 1111` с длинами 2, 2, 2, 3, 4, 4 и
средней длиной 2.44 — точно как в Таблице 12 пособия.
