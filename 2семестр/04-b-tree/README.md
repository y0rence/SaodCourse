# 04. Сравнение ДБД и АВЛ при добавлении вершин (`BTree`)

| Файл | Назначение |
|---|---|
| `b_tree.cpp` | добавление в ДБД (`addDBD`) и в АВЛ (`AddAVL`), обход ДБД, таблица характеристик обоих деревьев |

**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -Wextra -pedantic b_tree.cpp -o b_tree && ./b_tree
```

## Что делает программа

1. Формирует случайную перестановку чисел от 1 до 100 и добавляет их по одному в ДБД-дерево и в АВЛ-дерево.
2. Выводит обход ДБД слева направо.
3. Печатает таблицу: размер, контрольная сумма, высота и средняя высота для АВЛ и ДБД.
