# 04. Сравнение ДБД и АВЛ при добавлении вершин (`BTree`)

📘 **Теория:** [THEORY.md](THEORY.md)

📝 **Ответы и тесты:** [ответы на вопросы (QA.md)](QA.md) · [тесты (TESTS.md)](TESTS.md)

| Файл | Назначение |
|---|---|
| `b_tree.cpp` | добавление в ДБД (`addDBD`) и в АВЛ (`AddAVL`), обход ДБД, таблица характеристик обоих деревьев |

**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -Wextra -pedantic b_tree.cpp -o b_tree && ./b_tree
```

## Что делает программа

1. Формирует случайную перестановку чисел от 1 до 100 и добавляет их по одному в ДБД-дерево и в АВЛ-дерево.
2. Выводит обход ДБД слева направо.
3. Печатает таблицу: размер, контрольная сумма, высота и средняя высота для АВЛ и ДБД.

## 🧩 Как скомпилировать каждый файл

Команды для каждого исходника. Имя исполняемого файла совпадает с именем исходника.

### `b_tree.cpp`

Библиотеки не нужны, только компилятор.

**macOS** (clang):

```bash
clang++ -std=c++17 -Wall -o b_tree b_tree.cpp && ./b_tree
```

**Linux** (gcc / g++):

```bash
g++ -std=c++17 -Wall -o b_tree b_tree.cpp && ./b_tree
```

**Windows** (MinGW-w64, в терминале MSYS2 или PowerShell с g++ в PATH):

```bash
g++ -std=c++17 -Wall -o b_tree.exe b_tree.cpp
```
