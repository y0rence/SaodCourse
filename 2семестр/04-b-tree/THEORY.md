# Сравнение ДБД и АВЛ: теория

## Зачем сравнивать

И АВЛ-дерево, и ДБД — самобалансирующиеся деревья поиска. После каждой вставки они поддерживают баланс высот поддеревьев, поэтому операции поиска, вставки и удаления работают за `O(log n)`.

## АВЛ-дерево

Для каждой вершины баланс `b = h(правое) − h(левое)` принимает значения `-1, 0, +1`. Если после вставки баланс становится `±2`, выполняется один из поворотов:

- **LL** — одинарный правый поворот;
- **RR** — одинарный левый поворот;
- **LR** — двойной поворот (левый, затем правый);
- **RL** — двойной поворот (правый, затем левый).

Подробно: [АВЛ-дерево: теория](../06-avl-tree/THEORY.md).

## ДБД

В `b_tree.cpp` тот же набор поворотов `LLTurn`, `LRTurn`, `RRTurn`, `RLTurn`, но пересчёт баланса и признаки роста дерева (`VR`, `HR`) организованы по схеме из отчёта `AVL_DBD.pdf`. Этот PDF хранится вне репозитория.

## Что измеряет программа

При вставке случайной перестановки чисел `1..100` в оба дерева выводятся:

- размер (должен совпадать у обоих деревьев);
- контрольная сумма (сумма ключей, тоже совпадает);
- высота;
- средняя высота.

Чем меньше средняя высота, тем быстрее в среднем поиск. Для одного и того же набора ключей два сбалансированных дерева могут различаться по этим величинам.
