# Тест: Б-деревья и двоичные Б-деревья (ДБД)

Тест из 41 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Что такое сильноветвящееся дерево?**

- а) Дерево, у вершин которого много потомков
- б) Дерево из двух вершин
- в) Дерево без листьев
- г) Дерево с одним ключом

**2. Для чего применяют Б-деревья по пособию?**

- а) Для хранения во внешней памяти и уменьшения обращений к диску
- б) Для сортировки чисел
- в) Для шифрования
- г) Для хранения графа

**3. Что такое страница Б-дерева?**

- а) Одна вершина дерева, считываемая за одно обращение к диску
- б) Лист
- в) Корень
- г) Файл

**4. Кто предложил Б-деревья по пособию?**

- а) Р. Байер и Е. Маккрейт
- б) Адельсон-Вельский и Ландис
- в) Кнут
- г) Хоар

**5. Какой критерий роста Б-дерева по пособию?**

- а) Каждая страница (кроме одной) содержит от m до 2m элементов
- б) Все страницы одинаковы
- в) Элементов ровно m
- г) Элементов ровно 2m

**6. Что означает порядок m Б-дерева?**

- а) Число уровней
- б) Параметр, задающий число элементов страницы от m до 2m
- в) Число листьев
- г) Число ключей в корне


## Уровень 2 — средний

**7. Какие ограничения на число элементов k в корне Б-дерева порядка m?**

- а) m ≤ k ≤ 2m
- б) 1 ≤ k ≤ 2m
- в) k = m
- г) k ≤ m

**8. Какие ограничения на число элементов k в не корневой странице?**

- а) m ≤ k ≤ 2m
- б) 1 ≤ k ≤ m
- в) k = 2m
- г) k ≥ 2m

**9. Чему равно число указателей на странице с k элементами?**

- а) k − 1
- б) k
- в) k + 1
- г) 2k

**10. Все листья Б-дерева расположены:**

- а) На разных уровнях
- б) На одном уровне
- в) Только в корне
- г) Не обязательно

**11. Что такое минимальное число вершин Б-дерева высоты h (по пособию)?**

- а) 2(m+1)^(h−1) − 1
- б) h
- в) 2^h
- г) m·h

**12. Как растёт Б-дерево при переполнении страницы?**

- а) От корня к листьям
- б) От листьев к корню
- в) Вбок
- г) Не растёт

**13. Когда страница переполняется при добавлении?**

- а) Когда k > 2m
- б) Когда k < m
- в) Когда k = 0
- г) Никогда

**14. Что переносится в новую страницу при разделении?**

- а) m правых элементов страницы a
- б) Все элементы
- в) Корень
- г) Один элемент

**15. Что делается со средним элементом при разделении?**

- а) Переносится на уровень вверх в родительскую страницу
- б) Удаляется
- в) Становится листом
- г) Дублируется

**16. Что происходит, если разделение дошло до корня?**

- а) Высота дерева увеличивается
- б) Дерево разрушается
- в) Корень удаляется
- г) Ничего

**17. Как создаётся новый корень при разделении корневой страницы?**

- а) Из одного элемента
- б) Из двух нулевых элементов
- в) Из m элементов
- г) Копированием старого

**18. Что такое двоичное Б-дерево (ДБД)?**

- а) Б-дерево порядка 1 в виде двоичного дерева со страницами из одного или двух элементов
- б) Двоичное дерево без листьев
- в) Список
- г) Двоичное дерево поиска с весами

**19. Сколько ссылок на поддеревья имеет страница ДБД?**

- а) Одну
- б) Две или три
- в) Четыре
- г) Ни одной

**20. Что такое вертикальная ссылка в ДБД?**

- а) Ссылка на потомка
- б) Ссылка на том же уровне
- в) Ссылка на корень
- г) Ссылка на лист

**21. Что такое горизонтальная ссылка в ДБД?**

- а) Ссылка на вершину того же уровня (внутри страницы)
- б) Ссылка на потомка
- в) Ссылка на родителя
- г) Ссылка в корень

**22. Какую высоту по пособию имеет ДБД (log-оценка)?**

- а) log(n+1)
- б) n
- в) 2n
- г) log₁₀ n

**23. Какую альтернативу для ДБД называет пособие?**

- а) АВЛ-деревья
- б) Хеш-таблицы
- в) Списки
- г) Массивы

**24. Что показывает логическая переменная VR?**

- а) Вертикальный рост дерева (страница переполнилась)
- б) Горизонтальный рост
- в) Корень
- г) Листовость

**25. Что показывает логическая переменная HR?**

- а) Горизонтальный рост (новый элемент на той же странице)
- б) Вертикальный рост
- в) Высоту
- г) Размер

**26. Какие значения принимает BAL в ДБД по пособию?**

- а) −1, 0, 1
- б) 0 и 1
- в) 1..m
- г) Любые

**27. Когда BAL = 0 в ДБД?**

- а) Когда у вершины только вертикальные ссылки (одна вершина на странице)
- б) Когда есть горизонтальная ссылка вправо
- в) Всегда
- г) Никогда

**28. Когда BAL = 1 в ДБД?**

- а) Когда есть правая горизонтальная ссылка
- б) Когда вершина одна на странице
- в) Когда дерево пусто
- г) Когда есть корень

**29. В каком случае в ДБД вершина поднимается на уровень вверх (VR = 1)?**

- а) Когда на странице уже два элемента и добавляется новый
- б) Когда на странице один элемент
- в) Всегда
- г) Никогда


## Уровень 3 — сложный

**30. Какой алгоритм в пособии задаёт добавление в ДБД?**

- а) Добавление в ДБ-дерево (D, p) с флагами VR и HR
- б) Бинарный поиск
- в) Сортировка вставками
- г) Хеширование

**31. Какое начальное значение VR и HR по пособию?**

- а) Оба ложь
- б) Оба истина
- в) VR истина, HR ложь
- г) HR истина, VR ложь

**32. Как в алгоритме ДБД изменяется баланс при создании листа?**

- а) p.Balance := 0, VR := ИСТИНА
- б) p.Balance := 1
- в) p.Balance := −1
- г) Не изменяется

**33. Оценка высоты ДБД, если рассматривать его как обычное двоичное дерево:**

- а) h ≤ 2·log(n+1)
- б) h = n
- в) h = log n / 2
- г) h = 1

**34. Сравнение трудоёмкости поиска в ДБД и АВЛ по пособию:**

- а) Одинаковы по порядку величины
- б) ДБД всегда быстрее
- в) АВЛ не ищет
- г) Поиск в ДБД O(n)

**35. Что нужно для страниц ДБД в ОЗУ по пособию?**

- а) Динамическое размещение на основе списка из одного или двух элементов
- б) Массив фиксированного размера
- в) Хеш-таблица
- г) Файлы

**36. Почему в Б-дереве поиск на странице можно делать двоичным?**

- а) Элементы страницы упорядочены, поиск — двоичный при большом k
- б) Элементы не упорядочены
- в) Поиск невозможен
- г) Страница — один элемент

**37. Какой вывод о числе обращений к диску делает пособие для m = 255?**

- а) Высота меньше log n / 8, то есть в 8 раз меньше обращений, чем у двоичного дерева
- б) Столько же
- в) В 100 раз больше
- г) Не сравнивается

**38. Почему двоичное Б-дерево сложнее в балансировке, чем АВЛ?**

- а) Нужно различать вертикальные и горизонтальные ссылки и следить за одним уровнем листьев
- б) Нет сложностей
- в) Не хранит ключи
- г) Имеет один элемент

**39. Для каких случаев пособие советует АВЛ вместо ДБД?**

- а) Когда поиск происходит значительно чаще добавления
- б) Когда добавления чаще поиска
- в) Никогда
- г) Для строк

**40. Что происходит при VR = 1 и HR = 0 в ДБД?**

- а) Средний элемент поднимается на уровень вверх
- б) Элемент добавляется горизонтально
- в) Дерево удаляется
- г) Ничего

**41. Какая формула высоты Б-дерева порядка m с n элементами (п. 13.1)?**

- а) h = ⌈log_(m+1)((n+1)/2)⌉ + 1 (логарифм по основанию m+1)
- б) h = n
- в) h = 2
- г) h = 1
