# 07. Удаление из АВЛ-дерева поиска (`AVLDelete`)

| Файл | Назначение |
|---|---|
| `avl_delete.cpp` | программа: удаление по ключу (пункт 2 меню) и удаление 10 введённых вершин с выводом обхода (пункт 3) |
| `avl_delete_l36.cpp` | альтернативный вариант той же программы (лабораторная 3.6) |
| `Makefile` | сборка |

**Сборка и запуск:**

```bash
make       # сборка
make run   # сборка и запуск
make clean # удалить собранный файл
```

## Задания

1. Удаление всех вершин из АВЛ-дерева, построенного из 12 первых неповторяющихся символов ФИО, выполнено вручную (отчёт `AVL_guide_combined.pdf` хранится вне репозитория вместе с теорией и разбором программы).
2. Удаление вершины с заданным ключом (пункт 2 меню программы).
3. Удаление 10 вершин, введённых с клавиатуры, с выводом обхода слева направо после каждого удаления (пункт 3 меню).

Алгоритмы написаны по псевдокоду пособия «Структуры и алгоритмы обработки данных», раздел 12 (сбалансированные по высоте деревья).
