# Тест: удаление из АВЛ-дерева

Тест из 31 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Как начинается удаление вершины из АВЛ-дерева по пособию?**

- а) Как в СДП
- б) Сразу поворотом
- в) С балансировки корня
- г) Не начинается

**2. Что общего с добавлением?**

- а) Ничего
- б) Балансировка выполняется теми же поворотами
- в) Удаляется корень
- г) Нет общего

**3. Какой параметр показывает уменьшилась ли высота поддерева при удалении?**

- а) Рост
- б) Уменьшение
- в) Balance
- г) VR

**4. В каких вершинах может нарушаться баланс после удаления?**

- а) Только в корне
- б) В нескольких вершинах вдоль пути к корню
- в) Только в листьях
- г) Нигде

**5. Как удаляется вершина без поддеревьев?**

- а) Заменяется корнем
- б) Удаляется: p := NIL, Уменьшение := ИСТИНА
- в) Перестраивается дерево
- г) Ничего

**6. Какие процедуры балансировки введены для удаления?**

- а) BL и BR
- б) LL и RR
- в) BA и BB
- г) Только LR


## Уровень 2 — средний

**7. Какая процедура используется при уменьшении высоты левого поддерева?**

- а) BR
- б) BL
- в) del
- г) LL1

**8. Какая процедура используется при уменьшении высоты правого поддерева?**

- а) BL
- б) BR
- в) RR1
- г) del

**9. Что делает BL, если Balance = −1?**

- а) Balance := 1
- б) Balance := 0
- в) Поворот RL
- г) Ничего

**10. Что делает BL, если Balance = 0?**

- а) Balance := 1, Уменьшение := ЛОЖЬ
- б) Balance := −1
- в) Поворот LL
- г) Уменьшение := ИСТИНА

**11. Что делает BR, если Balance = 0?**

- а) Balance := −1, Уменьшение := ЛОЖЬ
- б) Balance := 1
- в) Поворот RR
- г) Ничего

**12. Какой случай требует поворот при BR и Balance = −1?**

- а) LL1 или LR в зависимости от p→Left→Balance
- б) RR1
- в) Ничего
- г) del

**13. Как удаляется вершина с двумя поддеревьями?**

- а) Заменой на самую правую вершину левого поддерева (процедура del)
- б) Заменой на корень
- в) Заменой на лист правого
- г) Невозможно

**14. Какая вершина физически удаляется при двух поддеревьях?**

- а) Удаляемая вершина всегда
- б) Самая правая вершина левого поддерева (её данные переносятся на место удаляемой)
- в) Корень
- г) Самая левая вершина правого

**15. Что делает процедура del при наличии правого потомка у r?**

- а) Рекурсивно спускается вправо и при Уменьшение вызывает BR
- б) Удаляет r без балансировки
- в) Поворачивает корень
- г) Ничего

**16. Чем отличаются LL1 и LL при удалении?**

- а) Ничем
- б) LL1 учитывает случай q→Bal = 0, которого при добавлении не бывает
- в) LL1 не меняет указатели
- г) LL1 — двойной поворот

**17. Какой случай не мог возникнуть при добавлении?**

- а) p→left→Bal = 0 (поэтому LL1 отличается от LL)
- б) Одинарный поворот
- в) Двойной поворот
- г) Вставка в пустое дерево

**18. Трудоёмкость удаления из АВЛ в худшем случае:**

- а) O(n)
- б) O(log n)
- в) O(1)
- г) O(n²)

**19. Почему удаление сложнее включения?**

- а) Потому что нарушения могут возникать во многих вершинах пути
- б) Потому что нет указателей
- в) Из-за хеша
- г) Потому что нет поворотов

**20. Какое максимальное число поворотов возможно при удалении?**

- а) Не более одного
- б) Поворот может потребоваться во всех вершинах пути поиска
- в) Два
- г) Ни одного


## Уровень 3 — сложный

**21. Какой наихудший случай по поворотам при удалении?**

- а) Удаление корня у идеального дерева
- б) Удаление самой правой вершины у плохого АВЛ (дерева Фибоначчи)
- в) Удаление листа
- г) Ни один

**22. Как часто по экспериментам пособия происходит поворот при удалении?**

- а) Каждый раз
- б) В одном случае из пяти
- в) В каждом втором
- г) Никогда

**23. Почему в BL при Balance = 1 нужна проверка правого потомка?**

- а) Потому что после уменьшения левой ветви перекос на правой стороне
- б) Для красоты
- в) Из-за LL
- г) Нет такой проверки

**24. Что вернёт удаление ключа, которого нет в АВЛ?**

- а) Изменённое дерево
- б) Дерево без изменений (Уменьшение остаётся ЛОЖЬ)
- в) Пустое дерево
- г) Ошибку памяти

**25. Почему после удаления процедуры BL и BR вызываются только при Уменьшение = ИСТИНА?**

- а) Для экономии времени: балансировка нужна только при уменьшении высоты
- б) Так задано случайно
- в) Для вывода
- г) Из-за указателей

**26. Что происходит в del, если у r нет правого потомка?**

- а) r заменяется левым потомком r, Уменьшение := ИСТИНА
- б) r удаляется полностью
- в) Корень меняется
- г) Ничего

**27. Корень 2 с левым потомком 1 и правым 4. После удаления 1 баланс корня станет:**

- а) 0
- б) 1 (правое поддерево выше), балансировка не нужна
- в) −1
- г) −2 (нужен поворот)

**28. В каком порядке выполняется балансировка при удалении?**

- а) Сверху вниз
- б) Снизу вверх от удалённой вершины к корню
- в) Случайно
- г) Сначала корень

**29. Какая переменная в процедуре BL выставляется ЛОЖЬ?**

- а) Уменьшение
- б) Рост
- в) Balance
- г) VR

**30. Почему удаление требует поворотов «во всех вершинах вдоль пути», а включение — не более одного?**

- а) Потому что при включении высота растёт не более чем на один уровень и балансировка гасит рост, а при удалении уменьшение может распространиться вверх
- б) Из-за случайности
- в) Потому что ключи уникальны
- г) Нет разницы

**31. Какой алгоритм использует пособие для поиска ключа при удалении?**

- а) Рекурсивный спуск по p→Data > x / < x, затем удаление
- б) Хеш-таблица
- в) Бинарный поиск по массиву
- г) Линейный обход
