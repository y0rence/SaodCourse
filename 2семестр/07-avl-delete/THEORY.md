# Удаление из АВЛ-дерева: теория

## Удаление как в дереве поиска

1. **Вершина — лист.** Удаляется без последствий для структуры.
2. **Один потомок.** Вершину заменяет её единственный потомок.
3. **Два потомка.** Вершину заменяет её **предшественник** (самая правая вершина левого поддерева) либо преемник. Предшественник затем удаляется из своего места, как лист или вершина с одним потомком.

## Восстановление баланса

После удаления высота поддерева может уменьшиться. Поэтому алгоритм поднимается от места удаления к корню и на каждом уровне:

- пересчитывает баланс вершины;
- если баланс стал `±2`, выполняет поворот (LL, RR, LR или RL, как при вставке).

Важное отличие от вставки: после поворота высота поддерева может уменьшиться или остаться прежней. Если баланс вершины-брата равен 0, одинарный поворот не уменьшает высоту, и подъём можно прекратить.

Подробная схема поворотов и псевдокод — в пособии «Структуры и алгоритмы обработки данных», раздел 12. Теория самих поворотов — в [АВЛ-дерево: теория](../06-avl-tree/THEORY.md).

## Псевдокод (из пособия, гл. 12.4)
Текст алгоритмов перенесён из пособия «Структуры и алгоритмы обработки данных» (Курапова, Мачикина). Ссылки на пункт и страницу — в заголовке каждого блока.

### Балансировка BL — уменьшилось левое поддерево (п. 12.4, с. 59)

```text
BL (p: pVertex, Уменьшение: boolean)
IF (p→Bal = -1) p→Bal := 0
ELSEIF (p→Bal = 0) p→Bal := 1, Уменьшение := ЛОЖЬ
ELSEIF (p→Bal = 1)
    IF (p→Left→Bal ≥ 0) <RR1-поворот>
    ELSE <RL - поворот> FI
FI
```

### Балансировка BR — уменьшилось правое поддерево (п. 12.4, с. 58)

```text
BR (p: pVertex, Уменьшение: boolean)
IF (p→Bal = 1) p→Bal := 0
ELSEIF (p→Bal = 0) p→Bal := -1, Уменьшение := ЛОЖЬ
ELSEIF (p→Bal = -1)
    IF (p→Left→Bal ≤ 0) <LL1 - поворот>
    ELSE <LR - поворот> FI
FI
```

### LL1-поворот (п. 12.4, с. 59)

```text
q := p→Left
IF (q→Bal = 0) p→Bal := -1, q→Bal := 1, Уменьшение := ЛОЖЬ
ELSE p→Bal := 0, q→Bal := 0
p→Left := q→Right
q→Right := p
p := q
```

### RR1-поворот (п. 12.4, с. 59)

```text
q := p→Right
IF (q→Bal = 0) p→Bal := 1, q→Bal := -1, Уменьшение := ЛОЖЬ
ELSE p→Bal := 0, q→Bal := 0
p→Right := q→Left
q→Left := p
p := q
```

### Удаление из АВЛ-дерева (п. 12.4, с. 59–60)

```text
Удаление из АВЛ-дерева (x: Данные, p: pVertex, Уменьшение: boolean)
IF (p = NIL) {ключа в дереве нет}
ELSE IF (p→Data > x) Удаление (x, p→Left, Уменьшение)
        IF Уменьшение BL (p, Уменьшение) FI
ELSE IF (p→Data < x) Удаление (x, p→Right, Уменьшение)
        IF Уменьшение BR (p, Уменьшение) FI
ELSE {удаление вершины по адресу p}
    q := p
    IF (q→Right = NIL) p := q→Left, Уменьшение := ИСТИНА
    ELSE IF (q→Left = NIL) p := q→Right, Уменьшение := ИСТИНА
    ELSE del (q→Left, Уменьшение)
        IF Уменьшение BL (p, Уменьшение) FI
    FI
    dispose(q)
FI
```

### Процедура del — замена на самую правую вершину левого поддерева (п. 12.4, с. 60)

```text
del (r: pVertex, Уменьшение: boolean)
IF (r→right ≠ NIL)
    del (r→right, Уменьшение)
    IF Уменьшение BR (r, Уменьшение) FI
ELSE q→Data := r→Data
    q := r
    r := r→Left
    Уменьшение := ИСТИНА
FI
```
