# Дерево оптимального поиска: теория

## Постановка

Есть `n` вершин с упорядоченными ключами `1..n` и весами `w₁..wₙ` (вес — частота обращения к ключу). Нужно построить двоичное дерево поиска, у которого **средневзвешенная высота** минимальна:

```
P = Σ wᵢ · hᵢ,      hᵢ — уровень вершины i (корень находится на уровне 1)
```

Отношение `P / Σ wᵢ` и есть средневзвешенная высота дерева.

## Матрицы алгоритма (пособие, п. 14.2)

**Матрица весов AW** (формула 1). Для интервала `i < j`:

```
AW[i][i] = 0
AW[i][j] = AW[i][j-1] + wⱼ
```

**Матрица взвешенных высот AP и корней AR** (формула 2). Для поддерева из вершин `i+1..j`:

```
AP[i][j] = min over k ∈ (i, j] { AP[i][k-1] + AP[k][j] } + AW[i][j]
AR[i][j] = argmin k
```

Вершины `k` перебираются только в диапазоне `AR[i][j-1] .. AR[i+1][j]`: это ограничение сокращает перебор, не меняя результата.

## Построение дерева

Корень всего дерева — `AR[0][n]`. Рекурсивно для отрезка `[L, R]` корень равен `AR[L][R]`, левое поддерево строится на `[L, k-1]`, правое — на `[k, R]`.

## Проверка

Для построенного дерева должно выполняться `AP[0][n] = Σ wᵢ · hᵢ`, то есть `AP[0][n] / AW[0][n]` совпадает со средневзвешенной высотой дерева. Программа выводит обе величины и сообщает, совпали ли они.

## Пример из пособия

Веса `60, 30, 10`: средневзвешенная высота равна `1.50`.
