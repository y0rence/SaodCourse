# Дерево оптимального поиска: теория

## Постановка

Есть `n` вершин с упорядоченными ключами `1..n` и весами `w₁..wₙ` (вес — частота обращения к ключу). Нужно построить двоичное дерево поиска, у которого **средневзвешенная высота** минимальна:

```
P = Σ wᵢ · hᵢ,      hᵢ — уровень вершины i (корень находится на уровне 1)
```

Отношение `P / Σ wᵢ` и есть средневзвешенная высота дерева.

## Матрицы алгоритма (пособие, п. 14.2)

**Матрица весов AW** (формула 1). Для интервала `i < j`:

```
AW[i][i] = 0
AW[i][j] = AW[i][j-1] + wⱼ
```

**Матрица взвешенных высот AP и корней AR** (формула 2). Для поддерева из вершин `i+1..j`:

```
AP[i][j] = min over k ∈ (i, j] { AP[i][k-1] + AP[k][j] } + AW[i][j]
AR[i][j] = argmin k
```

Вершины `k` перебираются только в диапазоне `AR[i][j-1] .. AR[i+1][j]`: это ограничение сокращает перебор, не меняя результата.

## Построение дерева

Корень всего дерева — `AR[0][n]`. Рекурсивно для отрезка `[L, R]` корень равен `AR[L][R]`, левое поддерево строится на `[L, k-1]`, правое — на `[k, R]`.

## Проверка

Для построенного дерева должно выполняться `AP[0][n] = Σ wᵢ · hᵢ`, то есть `AP[0][n] / AW[0][n]` совпадает со средневзвешенной высотой дерева. Программа выводит обе величины и сообщает, совпали ли они.

## Пример из пособия

Веса `60, 30, 10`: средневзвешенная высота равна `1.50`.

## Псевдокод (из пособия, гл. 14)
Текст алгоритмов перенесён из пособия «Структуры и алгоритмы обработки данных» (Курапова, Мачикина). Ссылки на пункт и страницу — в заголовке каждого блока.

### Вычисление матрицы весов AW (формула 1), п. 14.2, с. 76

```text
DO (i = 0,...,n)
    DO (j = i+1,...,n)
        Awij := Awi,j-1 + wj
    OD
OD
```

### Вычисление матриц AP и AR (формула 2), п. 14.2, с. 76

```text
DO (i = 0,...,n - 1)
    Api,i+1 := Awi,i+1
    Ari,i+1 := i+1
OD
DO (h = 2,...,n)
    DO (i = 0,...,n - h)
        j := i + h
        m := Ari,j-1
        min := Api,m-1 + Apm,j
        DO (k = m+1,...,Ari+1,j)
            x := Api,k-1 + Apk,j
            IF (x < min) m := k, min := x FI
        OD
        Api,j := min + Awi,j
        Ari,j := m
    OD
OD
```

### Создание дерева (L, R – границы массива вершин V, Root – указатель на корень), с. 77

```text
IF (L < R)
    k := ARL,R
    Добавить (Root, Vk)
    Создание дерева (L, k-1)
    Создание дерева (k, R)
FI
-- вызов: Создание дерева (L=0, R=n, Root=NIL)
```

### Приближённый алгоритм А1 (корень — вершина с наибольшим весом), п. 14.3, с. 77

```text
Root := NIL
DO (i = 1,...,n)  V[i].use := ЛОЖЬ  OD
DO (i = 1,...,n)
    max := 0, Index := 0
    DO (j = 1,...,n)
        IF (V[j].w > max и V[j].use = ЛОЖЬ)
            max := V[j].w
            Index := j
        FI
    OD
    V[index].use := ИСТИНА
    Добавление в СДП (Root, V[index])
OD
```

### Приближённый алгоритм А2 («центр тяжести»), п. 14.3, с. 78

```text
wes := 0, summa := 0
IF (L <= R)
    DO (i = L, L+1, …, R) wes := wes + V[i].w OD
    DO (i = L, L+1, …, R-1)
        IF (summa < wes/2 и summa + V[i].w >= wes/2) OD
        summa := summa + V[i].w
    OD
    Добавление в СДП (Root, V[i])
    A2(Root, L, i-1)
    A2(Root, i+1, R)
FI
```
