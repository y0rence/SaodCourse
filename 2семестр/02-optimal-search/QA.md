# Вопросы по теме «Деревья оптимального поиска»

Точный и приближённые алгоритмы построения ДОП.

Ответы даны строго по пособию «Структуры и алгоритмы обработки данных»; в скобках указан пункт и страница.

### 1. Какая информация, кроме ключей, необходима для построения дерева оптимального поиска (ДОП)?

Вес каждой вершины — величина, пропорциональная частоте поиска этой вершины (например, если из 100 операций поиска 15 приходятся на V1, то w1 = 15).

> 📖 п. 14.1, с. 72

### 2. Что такое вес вершины? Вес дерева?

Вес вершины Vi — w_i, пропорциональный частоте поиска этой вершины. Вес дерева W — сумма весов всех вершин.

> 📖 п. 14.1, с. 72

### 3. Напишите формулу средневзвешенной высоты дерева.

hср = (w1·h1 + w2·h2 + … + wn·hn) / W, где hi — высота вершины (корень на высоте 1), W — вес дерева.

> 📖 п. 14.1, с. 72–73

### 4. Дайте определение дерева оптимального поиска (ДОП).

Дерево поиска, имеющее минимальную средневзвешенную высоту, называется деревом оптимального поиска.

> 📖 п. 14.1, с. 72–73

### 5. В чем проблема точного алгоритма построения ДОП?

Число конфигураций из n вершин растёт экспоненциально, поэтому перебор нерационален. Точный алгоритм имеет трудоёмкость O(n³) при n→∞ (до сокращения поиска корня).

> 📖 п. 14.2, с. 74 и 76

### 6. На каком свойстве оптимальных деревьев основан точный алгоритм построения ДОП?

Свойство 1: P = PL + W + PR (взвешенная высота дерева равна сумме взвешенных высот поддеревьев плюс вес дерева). Свойство 2: все поддеревья ДОП также являются ДОП для соответствующих подмножеств вершин.

> 📖 п. 14.2, с. 74

### 7. Из каких вершин состоит оптимальное поддерево Tij?

Из вершин Vi+1, …, Vj (вершины с номерами от i+1 до j).

> 📖 п. 14.2, с. 74

### 8. Что содержит каждый элемент матрицы AWij?

Вес поддерева Tij: AWij = AWi,j−1 + wj (формула 1); AWii = 0.

> 📖 п. 14.2, с. 74

### 9. Что содержит каждый элемент матрицы APij?

Взвешенную высоту поддерева Tij: APij = AWij + min{APi,k−1 + APk,j}, i < k ≤ j (формула 2); APii = 0.

> 📖 п. 14.2, с. 74

### 10. Что содержит каждый элемент матрицы ARij?

Номер корневой вершины k* поддерева Tij, при котором достигается минимум в формуле 2.

> 📖 п. 14.2, с. 74

### 11. Как должны быть упорядочены данные для точного построения ДОП?

Множество вершин, входящих в дерево, упорядочено (по возрастанию ключей).

> 📖 п. 14.2, с. 74

### 12. Как построить ДОП, пользуясь матрицей AR?

Берём k = AR0,n и добавляем вершину Vk обычным алгоритмом добавления в дерево поиска; затем рекурсивно строим левое поддерево по AR0,k−1 и правое — по ARk,n. Алгоритм «Создание дерева(L, R)»: если L < R, то k = ARL,R, добавить Vk, создать (L, k−1), создать (k, R).

> 📖 п. 14.2, с. 74–76, 77

### 13. Какая закономерность в матрице AP позволяет уменьшить трудоемкость точного алгоритма построения ДОП?

Закономерность в матрице AR: ARi,j−1 ≤ ARij ≤ ARi+1,j. Поиск ARij ограничивается диапазоном ARi,j−1 … ARi+1,j, что снижает трудоёмкость до O(n²) при n→∞ (идея Д. Кнута).

> 📖 п. 14.2, с. 76

### 14. Какова трудоемкость точного алгоритма построения ДОП (по времени и по занимаемой памяти)?

По времени: O(n³) без ограничения поиска, с ограничением — O(n²). По памяти: существует около n²/2 значений APij.

> 📖 п. 14.2, с. 76

### 15. Сформулируйте идею приближенного алгоритма А1 построения ДОП. Как должны быть упорядочены данные?

В качестве корня берётся вершина с наибольшим весом; среди оставшихся снова выбирается вершина с наибольшим весом и помещается в левое или правое поддерево (по значению ключа), и т.д. Алгоритм реализуется добавлением в СДП в порядке убывания веса. Упорядоченность данных по ключам для А1 пособием не требуется.

> 📖 п. 14.3, с. 77

### 16. Сформулируйте идею приближенного алгоритма А2 построения ДОП. Как должны быть упорядочены данные?

Используется предварительно упорядоченный набор вершин. В качестве корня выбирается такая вершина, при которой разность весов левого и правого поддеревьев минимальна; далее действия повторяются для каждого поддерева.

> 📖 п. 14.3, с. 78

### 17. Как определяется «центр тяжести» в приближенном алгоритме А2?

Находится вершина Vk, для которой выполнены неравенства: сумма весов w1…wk−1 не больше W/2, а сумма w1…wk не меньше W/2 (то есть суммы по обе стороны от Vk примерно равны). Затем в качестве центра тяжести выбирается Vk, Vk−1 или Vk+1 — та, для которой разность весов левого и правого поддеревьев минимальна.

> 📖 п. 14.3, с. 78

### 18. Какова трудоемкость приближенных алгоритмов построения ДОП?

Время T = O(n·log n) (определяется сортировкой), память M = O(n). А1 по качеству приближения равносилен случайному дереву при n→∞; А2 асимптотически приближается к оптимальному дереву.

> 📖 п. 14.3, с. 79–80
