# Бинарное дерево: теория

## Основные понятия

- **Вершина** — элемент с данными и ссылками на левое и правое поддеревья.
- **Корень** — вершина без родителя.
- **Лист** — вершина без потомков.
- **Уровень** вершины — расстояние от корня, корень на уровне 1.
- **Высота** дерева — максимальный уровень.

## Обходы

| Обход | Порядок | Пример для дерева варианта 20 |
|---|---|---|
| Сверху вниз (прямой) | корень, левое, правое | A B D E F C |
| Слева направо (симметричный) | левое, корень, правое | E D F B A C |
| Снизу вверх (обратный) | левое, правое, корень | E F D B C A |

## Характеристики

- **Размер** — число вершин.
- **Контрольная сумма** — сумма данных всех вершин.
- **Высота** — число уровней.
- **Средняя высота** — `(Σ уровней вершин) / размер`.

Для дерева варианта 20 (A — корень; B, C — его потомки; D — левый потомок B; E и F — потомки D): размер 6, высота 4, сумма уровней 1+2+2+3+4+4 = 16, средняя высота 16/6 ≈ 2.67.
