# 05. Бинарное дерево: обходы и характеристики (`BinaryTree`)

| Файл | Назначение |
|---|---|
| `binary_tree.cpp` | дерево варианта 20 (вершины A–F), обходы сверху вниз, слева направо и снизу вверх, размер, контрольная сумма, высота, средняя высота |
| `Деревья_вопросы_и_ответы_СиАОД.docx` | вопросы и ответы по деревьям |
| `screenshot_binary_tree.png` | скриншот (в репозиторий не добавляется, см. `.gitignore`) |

**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -o binary_tree binary_tree.cpp && ./binary_tree
```

## Что делает программа

Строит заданное дерево из шести вершин и печатает три обхода, а затем размер, контрольную сумму, высоту и среднюю высоту. Значения вершин генерируются случайно (`rand() % 20 + 1`) с затравкой `time(NULL)`, поэтому при каждом запуске числа разные, а структура дерева одна и та же.
