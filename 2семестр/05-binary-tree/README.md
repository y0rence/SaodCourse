**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -o binary_tree binary_tree.cpp && ./binary_tree
```

## Что делает программа

Строит заданное дерево из шести вершин и печатает три обхода, а затем размер, контрольную сумму, высоту и среднюю высоту. Значения вершин генерируются случайно (`rand() % 20 + 1`) с затравкой `time(NULL)`, поэтому при каждом запуске числа разные, а структура дерева одна и та же.

## 🧩 Как скомпилировать каждый файл

Команды для каждого исходника. Имя исполняемого файла совпадает с именем исходника.

### `binary_tree.cpp`

Библиотеки не нужны, только компилятор.

**macOS** (clang):

```bash
clang++ -std=c++17 -Wall -o binary_tree binary_tree.cpp && ./binary_tree
```

**Linux** (gcc / g++):

```bash
g++ -std=c++17 -Wall -o binary_tree binary_tree.cpp && ./binary_tree
```

**Windows** (MinGW-w64, в терминале MSYS2 или PowerShell с g++ в PATH):

```bash
g++ -std=c++17 -Wall -o binary_tree.exe binary_tree.cpp
```
