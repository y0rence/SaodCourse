# Тест: двоичные деревья, обходы и характеристики

Тест из 39 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Что называется корнем дерева?**

- а) Вершина, у которой нет потомков
- б) Выделенная вершина дерева, из которой выходят дуги
- в) Самая правая вершина
- г) Вершина на уровне 2

**2. Как называются концевые вершины дерева без поддеревьев?**

- а) Корни
- б) Листья
- в) Ветви
- г) Уровни

**3. Что такое двоичное дерево по определению пособия?**

- а) Список с двумя указателями
- б) Отдельная вершина или вершина с левым и правым (возможно пустыми) двоичными деревьями
- в) Любой граф без циклов
- г) Массив из двух элементов

**4. Сколько вершин содержит пустое дерево?**

- а) 1
- б) 0
- в) n
- г) 2

**5. Какие данные хранит вершина дерева?**

- а) Только ключ
- б) Данные и указатели на левое и правое поддеревья
- в) Только указатели
- г) Номер уровня

**6. Какой порядок обхода «сверху вниз»?**

- а) Левое, корень, правое
- б) Корень, левое, правое
- в) Левое, правое, корень
- г) Правое, корень, левое

**7. Какой порядок обхода «слева направо»?**

- а) Корень, левое, правое
- б) Левое, корень, правое
- в) Левое, правое, корень
- г) Правое, левое, корень

**8. Какой порядок обхода «снизу вверх»?**

- а) Корень, левое, правое
- б) Левое, корень, правое
- в) Левое, правое, корень
- г) Корень, правое, левое

**9. Какой результат обхода «слева направо» для дерева: корень 1, левый потомок 2, правый 3?**

- а) 1 2 3
- б) 2 1 3
- в) 2 3 1
- г) 3 2 1

**10. Что означает «размер дерева»?**

- а) Высоту
- б) Число входящих в дерево вершин
- в) Сумму ключей
- г) Число листьев

**11. Что такое высота дерева h по пособию?**

- а) Число рёбер в дереве
- б) Число вершин в самой длинной ветви
- в) Число уровней минус один
- г) Число листьев


## Уровень 2 — средний

**12. Чему равен максимальный размер дерева высоты h?**

- а) h
- б) 2h
- в) 2^h − 1
- г) h²

**13. Чему равна минимально возможная высота дерева с n вершинами?**

- а) n
- б) log(n+1)
- в) n/2
- г) √n

**14. Что такое ветвь дерева?**

- а) Путь от корня к листу
- б) Любой путь между листьями
- в) Одна вершина
- г) Все вершины одного уровня

**15. Что вычисляет функция Размер(p) по пособию?**

- а) Высоту
- б) Размер = 1 + Размер(Left) + Размер(Right), при p = NIL — 0
- в) Сумму данных
- г) Средний уровень

**16. Что вычисляет функция Высота(p) при p = NIL?**

- а) 1
- б) 0
- в) −1
- г) Высоту левого поддерева

**17. Как по пособию вычисляется функция «Высота»?**

- а) 1 + max(Высота(Left), Высота(Right))
- б) Высота(Left) + Высота(Right)
- в) max(Размер(Left), Размер(Right))
- г) 1 + Высота(Left)

**18. Что суммирует функция СДП(p, L)?**

- а) Данные вершин
- б) Сумму длин путей от корня до каждой вершины (L — уровень вершины)
- в) Количество листьев
- г) Сумму ключей вершин уровня L

**19. По какой формуле вычисляется средняя высота дерева?**

- а) hср = Размер(Root) / СДП(Root, 1)
- б) hср = СДП(Root, 1) / Размер(Root)
- в) hср = Высота(Root) / 2
- г) hср = Сумма(Root) / Размер(Root)

**20. Что такое контрольная сумма дерева по пособию?**

- а) Число вершин
- б) Сумма данных всех вершин: Сумма = Data + Сумма(Left) + Сумма(Right)
- в) Высота дерева
- г) Сумма уровней

**21. Какой обход удобнее всего использовать для вывода дерева поиска в порядке возрастания ключей?**

- а) Сверху вниз
- б) Слева направо
- в) Снизу вверх
- г) Любой

**22. Для дерева из 6 вершин, у которого сумма уровней вершин равна 14, чему равна средняя высота?**

- а) 2
- б) 14/6 ≈ 2.33
- в) 6/14
- г) 3

**23. Что показывает средняя высота дерева?**

- а) Максимальную длину пути
- б) Среднюю длину пути от корня до вершины (усреднённую по числу вершин)
- в) Число листьев
- г) Число поддеревьев


## Уровень 3 — сложный

**24. Почему обходы дерева удобно программировать рекурсивно?**

- а) Так быстрее работает компилятор
- б) Рекурсивные процедуры повторяют определение двоичного дерева
- в) Рекурсия экономит память всегда
- г) Так нельзя иначе

**25. Дерево: корень 1, левый потомок 2 с левым потомком 4, правый потомок 3. Каков обход сверху вниз?**

- а) 1 2 4 3
- б) 1 3 2 4
- в) 4 2 1 3
- г) 2 4 1 3

**26. Для дерева 1 с левым 2 (потомки 4, 5) и правым 3 (потомок 6): чему равна сумма уровней?**

- а) 14
- б) 16
- в) 12
- г) 10

**27. Какой порядок обхода «снизу вверх» для того же дерева (1; 2(4,5); 3(6))?**

- а) 1 2 4 5 3 6
- б) 4 5 2 6 3 1
- в) 4 2 5 1 3 6
- г) 6 3 5 4 2 1

**28. Сколько вершин максимум в дереве высоты 4 по свойству пособия?**

- а) 4
- б) 8
- в) 15
- г) 16

**29. Высота дерева с n = 100 вершинами не меньше (по свойству 2):**

- а) log(101) ≈ 6.66
- б) 100
- в) 50
- г) 10

**30. Чем отличается утверждение «высота дерева» от «средней высоты дерева»?**

- а) Ничем
- б) Высота — максимальная длина ветви, средняя высота — усреднённая сумма длин путей по вершинам
- в) Высота — число листьев
- г) Средняя высота всегда целая

**31. Какой алгоритм по пособию вычисляет размер дерева без рекурсии?**

- а) Такого нет: пособие даёт рекурсивный алгоритм
- б) Цикл по уровням
- в) Сортировка
- г) Хеширование

**32. Какой обход даёт узлы дерева поиска по возрастанию?**

- а) Сверху вниз
- б) Слева направо
- в) Снизу вверх
- г) Ни один

**33. Что произойдёт с контрольной суммой при обходе? (по определению пособия)**

- а) Меняется
- б) Не зависит от порядка обхода — это сумма данных всех вершин
- в) Становится средней высотой
- г) Равна размеру

**34. Два дерева имеют одинаковый набор вершин, но разную форму. Что верно?**

- а) Размер у них разный
- б) Размер и контрольная сумма совпадают, высота и средняя высота могут различаться
- в) Все характеристики совпадают
- г) Высота всегда одинакова

**35. Почему средняя высота учитывает именно количество вершин?**

- а) Для удобства
- б) Пособие делит сумму длин путей на Размер(Root), то есть усредняет по вершинам
- в) Так принято в ГОСТ
- г) Это ошибка пособия

**36. Для вырожденного дерева (список из 5 вершин, каждая левая) чему равна высота?**

- а) 1
- б) 5
- в) 2
- г) 4

**37. Для того же вырожденного дерева из 5 вершин чему равна минимальная высота по свойству 2?**

- а) 1
- б) log 6 ≈ 2.58
- в) 5
- г) 0

**38. Какая функция по пособию возвращает сумму длин путей от корня?**

- а) Размер
- б) СДП(p, L) с начальным L = 1
- в) Высота
- г) Сумма

**39. Почему в формуле средней высоты стартовый уровень равен 1?**

- а) Так удобнее
- б) Корень находится на высоте 1 (пособие: корень расположен на высоте 1)
- в) Это опечатка
- г) Чтобы не делить на ноль
