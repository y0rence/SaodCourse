| `sdp.cpp` | СДП двумя способами (двойная косвенность и рекурсия), ИСДП из отсортированного массива, обходы и таблица характеристик |

**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -o sdp sdp.cpp && ./sdp
```

## Что делает программа

1. **Задание 1** — СДП из 12 букв ФИО (номера букв в алфавите: `16 2 6 18 14 12 19 4 11 3 13 1`), построенная двумя способами; выводятся обход слева направо, размер, контрольная сумма, высота и средняя высота.
2. **Задание 3** — 100 различных случайных чисел от 1 до 1000 вставляются в СДП (двойная косвенность и рекурсия); отдельно строится ИСДП из отсортированной копии тех же чисел.
3. **Задание 4** — таблица характеристик ИСДП, СДП1 и СДП2 для `n = 100`.

## 🧩 Как скомпилировать каждый файл

Команды для каждого исходника. Имя исполняемого файла совпадает с именем исходника.

### `sdp.cpp`

Библиотеки не нужны, только компилятор.

**macOS** (clang):

```bash
clang++ -std=c++17 -Wall -o sdp sdp.cpp && ./sdp
```

**Linux** (gcc / g++):

```bash
g++ -std=c++17 -Wall -o sdp sdp.cpp && ./sdp
```

**Windows** (MinGW-w64, в терминале MSYS2 или PowerShell с g++ в PATH):

```bash
g++ -std=c++17 -Wall -o sdp.exe sdp.cpp
```
