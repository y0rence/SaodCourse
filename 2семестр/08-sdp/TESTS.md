# Тест: случайное дерево поиска (СДП)

Тест из 31 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Что такое случайное дерево поиска?**

- а) Дерево, построенное из случайного массива ключей с последовательным добавлением в него элементов
- б) Дерево, где ключи случайны и не сортированы
- в) Дерево из двух вершин
- г) Дерево с весами

**2. Как добавляется первая вершина в пустое СДП?**

- а) Становится корнем
- б) Становится листом
- в) Удаляется
- г) Не добавляется

**3. Куда идёт вставка, если новый ключ меньше ключа текущей вершины?**

- а) Вправо
- б) В левое поддерево
- в) В корень
- г) В лист

**4. Что происходит при совпадении ключа в СДП?**

- а) Вставляется дубликат
- б) Вершина не добавляется (данные с ключом уже есть)
- в) Меняется корень
- г) Удаляется вершина

**5. Можно ли по пособию использовать СДП для хранения динамически меняющихся данных?**

- а) Нет
- б) Да — это главная причина существования СДП
- в) Только для сортировки
- г) Только для листьев


## Уровень 2 — средний

**6. Почему при добавлении нужен указатель на указатель?**

- а) Для экономии памяти
- б) Нужно изменить значение указателя, куда записывается новая вершина (двойная косвенность)
- в) Чтобы работать с массивом
- г) Для ускорения обхода

**7. В каком случае СДП вырождается в список?**

- а) Если ключи добавляются в случайном порядке
- б) Если ключи добавляются по возрастанию или убыванию
- в) Если дерево имеет два листа
- г) Никогда

**8. Чему равен предел отношения средних высот СДП и ИСДП при n→∞?**

- а) 1
- б) 2·ln 2 ≈ 1.386
- в) 2
- г) 0.5

**9. На сколько процентов по пособию средняя высота СДП больше, чем у ИСДП (в п. 12.1)?**

- а) 10%
- б) 40%
- в) 100%
- г) 2%

**10. Какова трудоёмкость добавления вершины в СДП по пособию?**

- а) O(n)
- б) O(log n) в среднем
- в) O(1)
- г) O(n log n)

**11. Почему СДП не гарантирует балансировку?**

- а) Потому что не сравнивает ключи
- б) Потому что порядок поступления ключей произвольный и может вырождать дерево
- в) Потому что нет корня
- г) Потому что нет листьев

**12. Что верно о СДП, построенном из ключей, поступивших в порядке 1 2 3 4 5 (пособие, пример 1)?**

- а) Сбалансированное дерево
- б) Вырожденное дерево высоты 5
- в) Дерево из двух листьев
- г) Пустое дерево

**13. Какой из поступлений ключей даёт вырожденный СДП? (пособие, пример 2)**

- а) 5 1 2 4 3
- б) 1 2 3 4 5 (пример 1 из рис. 33)
- в) Оба дают вырожденное
- г) Ни один

**14. Как связаны СДП и ИСДП по форме при одинаковых данных?**

- а) Всегда одинаковы
- б) Могут различаться; ИСДП — идеально сбалансировано, СДП — нет
- в) СДП всегда выше
- г) ИСДП не строится из СДП

**15. Что делает функция добавления при D < (*p)→Data по пособию?**

- а) p := @((*p)→Left)
- б) p := @((*p)→Right)
- в) Выход
- г) Удаление

**16. Какой порядок (по пособию) имеет сложность поиска в СДП при n→∞?**

- а) O(log n)
- б) O(n)
- в) O(n²)
- г) O(1)

**17. Верно ли: СДП при случайном порядке данных имеет среднюю высоту O(log n)?**

- а) Да
- б) Нет
- в) Только для n < 10
- г) Никогда


## Уровень 3 — сложный

**18. Можно ли сортировать данные с помощью построения СДП и обхода слева направо?**

- а) Нет никогда
- б) Да: обход слева направо даёт ключи по возрастанию для любого дерева поиска (по определению)
- в) Только для чисел
- г) Только для ИСДП

**19. Почему трудоёмкость добавления в СДП сравнима с поиском в двоичном дереве?**

- а) Потому что добавление — это поиск места вставки по пути поиска
- б) Потому что добавление не сравнивает ключи
- в) Потому что есть хеш
- г) Нет такого совпадения

**20. Какие два недостатка СДП назовёт пособие?**

- а) Дорогой и медленный
- б) Может выродиться в список; средняя высота заметно больше, чем у ИСДП
- в) Нет обходов; нет корня
- г) Требует хеш-таблицы

**21. Как ведёт себя СДП при вставке случайной перестановки 1..n (среднее)?**

- а) Высота n
- б) Средняя высота имеет порядок O(log n)
- в) Высота 1
- г) Всегда log₂ n точно

**22. Что означает «двойная косвенность» в алгоритме «Добавление в СДП (D, *Root)»?**

- а) Два корня
- б) Переменная p — указатель на указатель на вершину, значение *p — адрес вершины
- в) Два ключа в вершине
- г) Вставка двух элементов

**23. Для вставки ключа 5 в дерево с корнем 3 (левый 1, правый 7) куда попадёт 5?**

- а) Левое поддерево корня
- б) Правое поддерево корня, затем левое поддерево 7
- в) Сразу в корень
- г) Левое поддерево 1

**24. Какая последовательность сравнений выполняется при вставке 6 в дерево 5(3, 8)?**

- а) 6 < 5 → влево
- б) 6 > 5 → вправо; 6 < 8 → влево
- в) 6 = 5
- г) 6 > 8 → вправо

**25. Чем отличается случайное дерево поиска от ИСДП при одинаковом наборе ключей?**

- а) Ничем
- б) СДП зависит от порядка поступления, ИСДП строится из отсортированного массива и идеально сбалансировано
- в) ИСДП содержит повторы
- г) СДП не содержит корня

**26. Сколько вершин добавляется в дерево при вставке ключа, уже существующего в СДП?**

- а) Одна
- б) Ни одной
- в) Две
- г) Все

**27. Какой порядок поступления ключей приводит к вырожденному СДП?**

- а) Случайный
- б) Возрастающий (1 2 3 4 5)
- в) Любой, кроме отсортированного
- г) Такого порядка нет

**28. Какой вывод о среднем времени поиска в СДП по сравнению с ИСДП сделан в пособии?**

- а) СДП быстрее
- б) СДП даёт среднее время поиска на 40% больше, но построение проще
- в) Одинаково
- г) ИСДП медленнее

**29. Какой обход используется в задании 7 (п. 11.4) для подтверждения дерева поиска?**

- а) Слева направо
- б) Сверху вниз
- в) Снизу вверх
- г) Никакой

**30. Какое задание п. 11.4 предлагает построить СДП для возрастающих данных?**

- а) Задание 9
- б) Задание 1
- в) Задание 3
