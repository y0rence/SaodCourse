# Тест: ИСДП — идеально сбалансированное дерево поиска

Тест из 31 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Что означает «идеально сбалансированное дерево» (ИСД)?**

- а) Все листья на одном уровне
- б) Для каждой вершины размеры левого и правого поддеревьев отличаются не более чем на 1
- в) Высота каждого поддерева одинакова
- г) Все ключи одинаковы

**2. По какому параметру сбалансировано ИСД?**

- а) По высоте
- б) По размеру (числу вершин) поддеревьев
- в) По сумме ключей
- г) По весу

**3. Что такое двоичное дерево поиска?**

- а) Дерево с ключами в случайном порядке
- б) Дерево, в котором ключ каждой вершины больше ключей левого поддерева и меньше ключей правого
- в) Дерево, где все ключи чётные
- г) Дерево без листьев

**4. Есть ли одинаковые ключи в дереве поиска по пособию?**

- а) Да, сколько угодно
- б) Нет: по условию дерева поиска одинаковых ключей нет
- в) Только в корне
- г) Только у листьев

**5. С какого элемента начинается поиск в дереве поиска?**

- а) С листа
- б) С корня Root
- в) С самого левого листа
- г) С произвольной вершины

**6. Что возвращает поиск, если вершина с ключом x не найдена?**

- а) Корень
- б) Пустой указатель NIL
- в) Ключ x
- г) Нулевой уровень


## Уровень 2 — средний

**7. Если ключ текущей вершины меньше искомого x, куда переходит поиск?**

- а) Влево
- б) Вправо (p := p→Right)
- в) Назад к корню
- г) Остаётся на месте

**8. Чему равно максимальное число сравнений при поиске в дереве поиска высоты h?**

- а) h
- б) 2h
- в) h²
- г) log h

**9. Какую высоту имеет ИСД с n вершинами по пособию?**

- а) n
- б) hmin(n) = ⌈log(n+1)⌉
- в) n/2
- г) 2n

**10. Какой алгоритм строит ИСДП из массива?**

- а) Добавление элементов по одному в произвольном порядке
- б) Сортировка массива, затем в корень берётся средний элемент, левое и правое поддеревья строятся рекурсивно
- в) Обход слева направо
- г) Хеширование

**11. Какой элемент берётся корнем ИСДП при построении из отсортированного массива?**

- а) Первый
- б) Последний
- в) Средний: m = [(L+R)/2]
- г) Максимальный

**12. Какой будет высота ИСДП, построенного из 15 элементов?**

- а) 15
- б) 4
- в) 8
- г) 3

**13. Что является недостатком ИСДП по пособию?**

- а) Слишком большой поиск
- б) При добавлении нового элемента приходится строить дерево заново
- в) Нельзя хранить числа
- г) Нет обходов

**14. Какая трудоёмкость поиска по ИСДП (Cmax) по пособию?**

- а) n
- б) 2·log(n+1)
- в) n²
- г) log n / 2

**15. Верно ли, что все поддеревья ИСД также идеально сбалансированы?**

- а) Нет
- б) Да (свойство 2)
- в) Только корень
- г) Только листья

**16. Какой из обходов выдаёт ключи ИСДП по возрастанию?**

- а) Сверху вниз
- б) Слева направо
- в) Снизу вверх
- г) Никакой

**17. Сколько шагов нужно первым этапом построения ИСДП?**

- а) Сортировка массива
- б) Построение корня
- в) Удаление повторов
- г) Обход

**18. Что верно о ИСД из 3 вершин?**

- а) Корень и два листа
- б) Цепочка из трёх вершин
- в) Три корня
- г) Дерево без листьев


## Уровень 3 — сложный

**19. Для массива из 16 элементов по алгоритму ИСДП(L, R) при L=1, R=16 чему равна m?**

- а) 8
- б) [(1+16)/2] = 8
- в) 16
- г) 9

**20. Почему ИСДП обеспечивает минимальное среднее время поиска при равновероятных запросах?**

- а) Оно всегда бинарное
- б) Высота минимальна, поэтому среднее число сравнений минимально
- в) Листья расположены по кругу
- г) Ключи отсортированы в обратном порядке

**21. Чем отличаются ИСДП и произвольное дерево поиска с той же высотой?**

- а) Ничем
- б) ИСДП имеет размеры поддеревьев, различающиеся не более чем на 1
- в) ИСДП не содержит листьев
- г) ИСДП хранит веса

**22. Для построения ИСДП из неотсортированных данных нужно:**

- а) Ничего не делать
- б) Сначала отсортировать массив
- в) Построить дерево поиска вставками
- г) Использовать хеш

**23. Какая высота у ИСДП из 100 вершин (hmin = ⌈log(n+1)⌉)?**

- а) 7
- б) 100
- в) 50
- г) 10

**24. Что проверяет логическая функция «Дерево поиска» по пособию?**

- а) Баланс высот
- б) Выполнение условия ключей во всех поддеревьях рекурсивно
- в) Размер дерева
- г) Наличие корня

**25. Почему ИСДП не является удобным для частых вставок?**

- а) Из-за размера узлов
- б) Каждая вставка требует полного перестроения дерева
- в) Нельзя сравнивать ключи
- г) Вставка запрещена

**26. Верно ли, что ИСДП — это АВЛ-дерево?**

- а) Да всегда
- б) Да: ИСДП является и АВЛ-деревом, обратное неверно
- в) Нет никогда
- г) Только при n = 2

**27. Какое значение имеет выражение m = [(L+R)/2] при L > R в алгоритме ИСДП?**

- а) Не вычисляется: ИСДП := NIL
- б) m = 0
- в) m = L
- г) m = R

**28. Сколько раз вызывается рекурсия для построения ИСДП из n вершин?**

- а) n
- б) Около n вызовов (по одному на вершину)
- в) log n
- г) n²

**29. Какая наименьшая высота у дерева с n = 7 вершинами?**

- а) 3
- б) 7
- в) 4
- г) 2

**30. Что произойдёт, если строить ИСДП из неотсортированного массива по тому же алгоритму?**

- а) Получится ИСДП
- б) Дерево может не быть ИСДП (условие построения нарушается)
- в) Ничего
- г) Массив отсортируется сам

**31. Для ИСДП из 2^k − 1 вершин (полное дерево) высота равна:**

- а) k
- б) 2^k
- в) k−1
- г) k+1
