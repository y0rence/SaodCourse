# 03. Идеально сбалансированное дерево поиска (`ISDP`)

📘 **Теория:** [THEORY.md](THEORY.md)

📝 **Ответы и тесты:** [ответы на вопросы (QA.html)](QA.html) · [тесты с автопроверкой (tests.html)](tests.html)

| Файл | Назначение |
|---|---|
| `isdp.c` | построение ИСДП из отсортированного массива, обходы, размер, контрольная сумма, высота, средняя высота |
| `report.html` | отчёт по ИСДП (открывается в браузере) |

**Сборка и запуск:**

```bash
gcc -std=c99 -o isdp isdp.c && ./isdp
```

## Что делает программа

1. **Задание 1** — ИСДП из 12 неповторяющихся букв ФИО: массив сортируется вставками, дерево строится рекурсивно (корень — средний элемент отрезка), выводятся исходный и упорядоченный массивы, обход слева направо и характеристики.
2. **Задания 2–3** — ИСДП из 100 случайных чисел от 1 до 999 с выводом обхода и характеристик.

Характеристики: размер, контрольная сумма, высота и средняя высота дерева (сумма уровней вершин, делённая на размер).

## 🧩 Как скомпилировать каждый файл

Команды для каждого исходника. Имя исполняемого файла совпадает с именем исходника.

### `isdp.c`

Библиотеки не нужны, только компилятор.

**macOS** (clang):

```bash
clang -std=c11 -Wall -o isdp isdp.c -lm && ./isdp
```

**Linux** (gcc / g++):

```bash
gcc -std=c11 -Wall -o isdp isdp.c -lm && ./isdp
```

**Windows** (MinGW-w64, в терминале MSYS2 или PowerShell с g++ в PATH):

```bash
gcc -std=c11 -Wall -o isdp.exe isdp.c -lm
```
