# Идеально сбалансированное дерево поиска (ИСДП): теория

## Определение

ИСДП — дерево поиска, в котором для каждой вершины количество вершин в левом и правом поддеревьях отличается не более чем на 1. Такое дерево имеет минимально возможную высоту для заданного числа вершин.

## Построение

1. Ключи сортируются по возрастанию.
2. Корнем берётся средний элемент отрезка `[L, R]`: `m = (L + R) / 2`.
3. Рекурсивно строятся левое поддерево на `[L, m-1]` и правое на `[m+1, R]`.

Так из отсортированного массива получается дерево за `O(n)` после сортировки.

## Характеристики

| Величина | Смысл |
|---|---|
| Размер | число вершин `n` |
| Контрольная сумма | сумма всех ключей; совпадает с суммой исходного массива, значит ни один ключ не потерян |
| Высота | `⌊log₂ n⌋ + 1` |
| Средняя высота | `(Σ уровней вершин) / n` |

Средняя высота — ключевой показатель эффективности поиска: среднее число сравнений при успешном поиске равно средней высоте.

### Дерево поиска — проверка (п. 10.1, с. 44)

```text
Дерево поиска := ИСТИНА
IF (p ≠ NIL и ((p→Left ≠ NIL и (p→Data ≤ p→Left→Data или
                  не Дерево поиска (p→Left)))
      или (p→Right ≠ NIL и (p→Data ≥ p→Right→Data или
                  не Дерево поиска (p→Right)))))
    Дерево поиска := ЛОЖЬ
FI
```

### Поиск вершины с ключом X (п. 10.1, с. 44–45)

```text
p := Root
DO (p ≠ NIL)
    IF (p→Data < x) p := p→Right
    ELSEIF (p→Data > x) p := p→Left
    ELSE OD { p→Data = x }
OD
IF (p ≠ NIL) <вершина найдена>
ELSE <вершина не найдена>
```

### Построение ИСДП (п. 10.2, с. 46)

```text
ИСДП (L, R)
IF (L > R) ИСДП := NIL
ELSE m := [(L+R) / 2]
    <Выделяем память для p>
    p→Data := A[m]
    p→Left := ИСДП (L, m-1)
    p→Right := ИСДП (m+1, R)
    ИСДП := p
FI
```
