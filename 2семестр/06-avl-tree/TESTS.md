# Тест: АВЛ-деревья

Тест из 34 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Кто предложил АВЛ-деревья?**

- а) Курапова и Мачикина
- б) Адельсон-Вельский и Ландис
- в) Кнут и Байер
- г) Хоар и Нейман

**2. Что такое АВЛ-дерево по пособию?**

- а) Дерево поиска, у которого высоты левого и правого поддеревьев каждой вершины отличаются не более чем на 1
- б) Дерево с весами
- в) Дерево из листьев
- г) Б-дерево

**3. Какие значения принимает показатель баланса Balance?**

- а) 0 и 1
- б) −1, 0, 1
- в) 1..n
- г) Любые целые

**4. Что означает Balance = −1?**

- а) Правое поддерево выше на 1
- б) Левое поддерево выше на 1
- в) Высоты равны
- г) Вершина листовая

**5. Что означает Balance = 0?**

- а) Высоты поддеревьев одинаковы
- б) Левое выше
- в) Правое выше
- г) Вершина пустая

**6. Сколько поворотов перечислено в пособии?**

- а) Один
- б) Два
- в) Четыре: LL, LR, RR, RL
- г) Восемь

**7. Является ли АВЛ-дерево деревом поиска?**

- а) Нет
- б) Да
- в) Только для чисел
- г) Только для строк


## Уровень 2 — средний

**8. Какой поворот применяется при вставке в левое поддерево левого потомка (LL)?**

- а) Одинарный правый поворот
- б) Двойной поворот
- в) Левый поворот
- г) Никакой

**9. Какой поворот требуется при вставке в правое поддерево левого потомка (LR)?**

- а) Двойной поворот
- б) Одинарный RR
- в) Одинарный LL
- г) Не требуется

**10. Что изменяется в поворотах при вставке, кроме переустановки указателей?**

- а) Ничего
- б) Значения показателей баланса вершин
- в) Ключи
- г) Корень всегда

**11. Чему равна трудоёмкость включения вершины в АВЛ-дерево в худшем случае?**

- а) O(n)
- б) O(log n)
- в) O(1)
- г) O(n²)

**12. Какая логическая переменная показывает, выросло ли дерево?**

- а) Уменьшение
- б) Рост
- в) Баланс
- г) VR

**13. Что делает алгоритм добавления после вставки новой вершины?**

- а) Удаляет корень
- б) Двигается назад по пути поиска к корню и ищет вершину с нарушенным балансом
- в) Сортирует
- г) Ничего

**14. Какой будет новая вершина с Balance после создания листа?**

- а) 1
- б) 0
- в) −1
- г) NIL

**15. Сколько поворотов может потребоваться при добавлении одной вершины?**

- а) Не более одного
- б) Всегда два
- в) Столько же, сколько высота
- г) Ни одного

**16. Какой вывод сделан пособием о верхней границе высоты АВЛ относительно ИСДП?**

- а) На 100%
- б) На 45% независимо от количества вершин
- в) На 1 уровень
- г) Не ограничена

**17. Что такое плохое АВЛ-дерево?**

- а) АВЛ с максимальным числом вершин
- б) АВЛ с наименьшим числом вершин при фиксированной высоте
- в) Дерево без корня
- г) Дерево с повторами

**18. Почему деревья Фибоначчи названы так?**

- а) Потому что ключи — числа Фибоначчи
- б) Потому что Th = <Th−1, x, Th−2>, построение напоминает числа Фибоначчи
- в) Из-за золотого сечения в обходе
- г) Из-за случайности

**19. По какой формуле считается число вершин дерева Фибоначчи?**

- а) nh = nh−1 + 1 + nh−2
- б) nh = 2·nh−1
- в) nh = h
- г) nh = n0 + n1

**20. Какой случай возможен при включении в левое поддерево, если hL = hR?**

- а) Баланс нарушен
- б) Баланс не нарушен, поддеревья станут разной высоты
- в) Дерево ломается
- г) Поворот LR

**21. Если hL < hR и вставка в левое поддерево, что происходит?**

- а) Баланс нарушается
- б) Высоты станут равны, баланс улучшается
- в) Вставка запрещена
- г) Создаётся новый корень

**22. Если hL > hR и вставка в левое поддерево, что требуется?**

- а) Ничего
- б) Перестройка дерева поворотом
- в) Удаление
- г) Сортировка


## Уровень 3 — сложный

**23. Почему после двойного поворота LR баланс корня r становится 0?**

- а) Так задано
- б) r→Balance := 0 в алгоритме LR (после переустановки)
- в) Потому что корень всегда 0
- г) Ошибка пособия

**24. Какой поворот применяется в правой ветви при RL?**

- а) Двойной: сначала RR, затем LL
- б) Двойной: вращение правого потомка влево, затем корня вправо
- в) Одинарный LL
- г) Не применяется

**25. Почему вставка не может приводить к случаю p→left→Balance = 0?**

- а) Не может — пособие отмечает это в п. 12.4 для LL1 (при добавлении такого случая нет)
- б) Потому что дерево пустое
- в) Потому что ключи уникальны
- г) Из-за LR

**26. Какова высота АВЛ по нижней границе (пособие): log(n+1) ≤ h? Для n = 7 минимум?**

- а) 3
- б) 7
- в) 2
- г) 4

**27. Какой вид имеет «худший случай» для АВЛ по высоте (относительно ИСДП)?**

- а) Ровное дерево
- б) Плохое АВЛ-дерево (дерево Фибоначчи)
- в) Линейный список
- г) Полное дерево

**28. Может ли АВЛ-дерево быть ИСДП?**

- а) Никогда
- б) Да, ИСДП является АВЛ-деревом
- в) Только при n = 1
- г) Только при n = 2

**29. Верно ли, что каждое АВЛ-дерево — ИСДП?**

- а) Да
- б) Нет: обратное утверждение неверно
- в) Только для чётного n
- г) Только для листьев

**30. Почему АВЛ даёт гарантию O(log n), а СДП — нет?**

- а) Потому что АВЛ балансируется поворотами после каждой вставки
- б) Потому что у АВЛ нет указателей
- в) Потому что АВЛ хранит ключи
- г) Потому что ИСДП

**31. Какой из перечисленных — компромисс АВЛ между ИСДП и СДП?**

- а) Строгая идеальная балансировка
- б) Менее строгое определение сбалансированности, дающее простую перестройку
- в) Отсутствие баланса
- г) Хеширование

**32. Какая переменная применяется при вставке для выхода из подъёма по пути?**

- а) Рост
- б) Balance
- в) Размер
- г) VR

**33. Сколько раз в среднем по экспериментам пособия на одно включение приходится поворот?**

- а) Один на два включения
- б) Два на одно
- в) Каждое включение
- г) Ни разу

**34. Почему АВЛ предпочтительнее для поиска, чем для частых добавлений по сравнению с ДБД?**

- а) Поиск в АВЛ быстрее, так как реже перестраивается структура
- б) Нет различий
- в) ДБД быстрее ищет
- г) АВЛ не ищет
