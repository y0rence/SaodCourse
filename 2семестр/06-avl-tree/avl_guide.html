AVL-дерево: псевдокод и обходы

Вставка, балансировка, построение из набора, обходы (рекурсивные и итеративные)

1. Структура узла

ЗАПИСЬ Узел:
    key      // ключ
    left     // левый потомок (или NIL)
    right    // правый потомок (или NIL)
    height   // высота поддерева (лист = 1)

2. Вспомогательные функции

ФУНКЦИЯ height(node):
    ЕСЛИ node = NIL: ВЕРНУТЬ 0
    ВЕРНУТЬ node.height

ПРОЦЕДУРА updateHeight(node):
    node.height = 1 + max(height(node.left), height(node.right))

ФУНКЦИЯ balanceFactor(node):
    ВЕРНУТЬ height(node.left) - height(node.right)

Фактор балансировки должен быть в диапазоне {-1, 0, +1}. Если он выходит за него, дерево нужно перебалансировать.

3. Повороты

ФУНКЦИЯ rotateRight(y):          // левый случай, малый правый поворот
    x = y.left
    T2 = x.right
    x.right = y
    y.left = T2
    updateHeight(y)
    updateHeight(x)
    ВЕРНУТЬ x                    // новый корень поддерева

ФУНКЦИЯ rotateLeft(x):           // правый случай, малый левый поворот
    y = x.right
    T2 = y.left
    y.left = x
    x.right = T2
    updateHeight(x)
    updateHeight(y)
    ВЕРНУТЬ y

4. Балансировка

ФУНКЦИЯ rebalance(node):
    updateHeight(node)
    bf = balanceFactor(node)

    // Левое поддерево тяжелее
    ЕСЛИ bf > 1:
        // LL: вставили в левое-левое
        ЕСЛИ balanceFactor(node.left) >= 0:
            ВЕРНУТЬ rotateRight(node)
        // LR: вставили в левое-правое
        ИНАЧЕ:
            node.left = rotateLeft(node.left)
            ВЕРНУТЬ rotateRight(node)

    // Правое поддерево тяжелее
    ЕСЛИ bf < -1:
        // RR: вставили в правое-правое
        ЕСЛИ balanceFactor(node.right) <= 0:
            ВЕРНУТЬ rotateLeft(node)
        // RL: вставили в правое-левое
        ИНАЧЕ:
            node.right = rotateRight(node.right)
            ВЕРНУТЬ rotateLeft(node)

    ВЕРНУТЬ node                 // баланс в порядке
Правило выбора поворота: смотрим на фактор балансировки узла и его тяжелого ребёнка. Если ребёнок тяжелее в ту же сторону, поворот одинарный. Если в противоположную, сначала поворачиваем ребёнка, затем сам узел.

5. Вставка

ФУНКЦИЯ insert(node, key):
    // 1. Обычная вставка в BST
    ЕСЛИ node = NIL:
        ВЕРНУТЬ новый Узел(key, height = 1)
    ЕСЛИ key < node.key:
        node.left = insert(node.left, key)
    ИНАЧЕ ЕСЛИ key > node.key:
        node.right = insert(node.right, key)
    ИНАЧЕ:
        ВЕРНУТЬ node            // дубликаты не вставляем

    // 2. Обновление высот и балансировка при возврате из рекурсии
    ВЕРНУТЬ rebalance(node)

Вызов: root = insert(root, key)

6. Построение дерева из набора

ФУНКЦИЯ buildAVL(keys):
    root = NIL
    ДЛЯ КАЖДОГО key ИЗ keys:      // порядок важен!
        root = insert(root, key)
    ВЕРНУТЬ root

Форма дерева зависит от порядка вставки, поэтому порядок элементов из условия нужно соблюдать.

7. Обходы (рекурсивные)

ОбходПорядокНазвание в курсе
inorderлевый, корень, правыйСДП (симметричный)
preorderкорень, левый, правыйКЛП (прямой)
postorderлевый, правый, кореньЛПК (обратный)
level-orderпо уровням, сверху внизобход в ширину
ПРОЦЕДУРА inorder(node):         // СДП: левый, корень, правый
    ЕСЛИ node = NIL: ВЫЙТИ
    inorder(node.left)
    ВЫВЕСТИ node.key
    inorder(node.right)

ПРОЦЕДУРА preorder(node):        // корень, левый, правый
    ЕСЛИ node = NIL: ВЫЙТИ
    ВЫВЕСТИ node.key
    preorder(node.left)
    preorder(node.right)

ПРОЦЕДУРА postorder(node):       // левый, правый, корень
    ЕСЛИ node = NIL: ВЫЙТИ
    postorder(node.left)
    postorder(node.right)
    ВЫВЕСТИ node.key

8. Обход в ширину (по уровням)

ПРОЦЕДУРА levelOrder(root):
    ЕСЛИ root = NIL: ВЫЙТИ
    очередь Q = [root]
    ПОКА Q не пуста:
        node = Q.dequeue()
        ВЫВЕСТИ node.key
        ЕСЛИ node.left ≠ NIL:  Q.enqueue(node.left)
        ЕСЛИ node.right ≠ NIL: Q.enqueue(node.right)

9. ИСДП: итеративный симметричный обход

Рекурсия заменяется явным стеком. Спускаемся влево до конца, складывая узлы в стек, затем извлекаем узел, выводим его и переходим в правое поддерево.

ПРОЦЕДУРА inorderIterative(root):
    стек S = пустой
    cur = root

    ПОКА cur ≠ NIL ИЛИ S не пуст:
        // Спускаемся влево, запоминая пройденные узлы
        ПОКА cur ≠ NIL:
            S.push(cur)
            cur = cur.left

        // Извлекаем узел, выводим его, идём вправо
        cur = S.pop()
        ВЫВЕСТИ cur.key
        cur = cur.right

10. Итеративный прямой обход (КЛП)

ПРОЦЕДУРА preorderIterative(root):
    ЕСЛИ root = NIL: ВЫЙТИ
    стек S = [root]

    ПОКА S не пуст:
        node = S.pop()
        ВЫВЕСТИ node.key
        ЕСЛИ node.right ≠ NIL: S.push(node.right)
        ЕСЛИ node.left ≠ NIL:  S.push(node.left)

Правый ребёнок кладётся в стек первым, поэтому левый извлекается раньше.

11. Пример для самопроверки

Набор: 5, 3, 8, 1, 4, 7, 9, 2, 6 (вставляем по порядку). Ни один поворот не понадобится.

5 / \ 3 8 / \ / \ 1 4 7 9 \ / 2 6
ОбходРезультат
inorder (СДП и ИСДП)1 2 3 4 5 6 7 8 9
preorder (КЛП)5 3 1 2 4 8 7 6 9
postorder (ЛПК)2 1 4 3 6 7 9 8 5
level-order5 3 8 1 4 7 9 2 6
Задание для поворотов: постройте AVL из наборов 10, 20, 30 (RR), 30, 20, 10 (LL), 30, 10, 20 (LR) и 10, 30, 20 (RL). Для каждого случая нарисуйте дерево до и после балансировки.

12. Чек-лист для самостоятельной работы

  • Вставка начинается как в обычном BST, а балансировка выполняется при возврате из рекурсии.
  • Повороты проверяют ребёнка: если он тяжелее в ту же сторону, поворот одинарный, иначе двойной.
  • Высоты обновляются снизу вверх, поэтому updateHeight вызывается перед проверкой баланса.
  • Inorder на BST всегда даёт отсортированный список, это удобная проверка.
  • ИСДП: почему cur = cur.right после вывода, а не cur = cur.left.
  • Почему ИСДП и рекурсивный СДП дают одинаковый результат, и чем различаются по памяти (явный стек против стека вызовов).
  • Для preorder: почему правый ребёнок кладётся в стек раньше левого.
