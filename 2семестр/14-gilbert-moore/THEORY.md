# Код Гилберта-Мура

Алфавитный код Гилберта-Мура — префиксный код, у которого кодовые слова лексикографически упорядочены: `φ(a1) ≤ φ(a2) ≤ … ≤ φ(an)`. Кодовое слово берётся из середины интервала, отведённого символу, поэтому порядок алфавита сохраняется, а длина каждого слова на единицу больше, чем в коде Шеннона.

## Основные формулы

| Величина | Формула |
|---|---|
| Вероятность символа | `P_i = n_i / N`, где `n_i` — частота символа, `N` — общее число символов |
| Энтропия | `H = −Σ P_i · log₂ P_i` |
| Средняя длина кодового слова | `Lcp = Σ P_i · L_i` |
| Избыточность кода | `r = Lcp − H` |
| Неравенство Крафта | `Σ 2^(−L_i) ≤ 1` |

Код называется **префиксным**, если ни одно кодовое слово не является началом другого, и **алфавитным**, если кодовые слова упорядочены так же, как символы алфавита. Для префиксного кода выполняется неравенство Крафта.

## Алгоритм построения

1. Символы упорядочивают и вычисляют середины их интервалов: `Q_i = p1 + … + p_(i−1) + p_i / 2`, причём `Q_0 = 0` и `Q_i < 1`.
2. Каждую сумму `Q_i` представляют в двоичной системе счисления.
3. Кодовым словом символа `a_i` берутся первые `L_i = ⌈−log₂ p_i⌉ + 1` бит двоичной дроби `Q_i`.

## Гарантии и свойства

- код алфавитный: кодовые слова лексикографически упорядочены по алфавиту;
- код префиксный, поэтому неравенство Крафта выполняется;
- средняя длина удовлетворяет `Lcp < H + 2`, то есть избыточность `r < 2`;
- длина каждого кодового слова ровно на единицу больше, чем в коде Шеннона.

## Пример из пособия

При вероятностях `0.36, 0.18, 0.18, 0.12, 0.09, 0.07` получаются длины `3, 4, 4, 5, 5, 5` (таблица 13 пособия):

```text
Lcp = 0.36·3 + 0.18·4 + 0.18·4 + 0.12·5 + 0.09·5 + 0.07·5 = 3.92 < 2.37 + 2 = H + 2.
```

## Связь с программой

Реализация — `GilbertMoore.cpp` (задания 2–4), текст `proizvedenie_11kb.txt` (57 букв, `N = 4489`): неравенство Крафта `0.337280 ≤ 1` выполняется, энтропия `H = 4.780912`, средняя длина `Lcp = 6.379372`, избыточность `r = 1.598460`. Граница пособия выполняется: `6.379372 < 4.780912 + 2 = 6.780912`, то есть `r < 2`. Длина кода на единицу больше длины кода Шеннона (`5.379372`). Подробности — в [README](README.md).
