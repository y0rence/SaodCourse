# 14. Код Гилберта-Мура (задания 2–4)

> **Интерактивная страница:** [lab.html](lab.html) — пошаговый проигрыватель с подсветкой кода (псевдокод ↔ исходный файл).

[Теория](THEORY.md)

Алфавитный код Гилберта-Мура по шагам 1–3 пособия СиАОД (п. 16.5):
`Q_i = p1 + ... + p_{i-1} + p_i/2` → двоичное представление `Q_i` →
кодовое слово = первые `⌈−log2 p_i⌉ + 1` бит дробной части `Q_i`.

|---|---|
| `GilbertMoore.cpp` | программа (задания 2, 3 и 4) |
| `proizvedenie_11kb.txt` | текст произведения, 11299 байт (≥ 10 КБ по условию) |

## Задания

1. **Задание 2** — строит код Гилберта-Мура и выводит таблицу:
   Символ | Вероятность символа | Кодовое слово | Длина кодового слова.
2. **Задание 3** — проверяет неравенство Крафта, считает энтропию `H`,
   среднюю длину `Lср` и избыточность `r = Lср − H`, выводит таблицу
   (Неравенство Крафта | Энтропия исходного текста | Средняя длина
   кодового слова | Избыточность кода Гилберта-Мура) и **сравнивает
   среднюю длину с кодами Шеннона, Фано и Хаффмана** (Шеннон — по
   формуле `⌈−log2 p⌉`, Фано и Хаффман строятся заново теми же
   функциями, что в работах 12 (Фано) и 13 (Хаффман)).
3. **Задание 4** — кодирует первые 100 символов текста, выводит
   закодированную последовательность, её длину и коэффициент сжатия.

## Результаты на тексте из 11 КБ (N = 4489 символов, 57 букв)

Задание 3 — оценка кода Гилберта-Мура:

| Неравенство Крафта | Энтропия H | Средняя длина Lср | Избыточность r |
|---|---|---|---|
| 0.337280 ≤ 1, выполняется | 4.780912 | 6.379372 | 1.598460 |

Сравнение средних длин кодовых слов:

| Код | Средняя длина кодового слова |
|---|---|
| Гилберта-Мура | 6.379372 |
| Шеннона | 5.379372 |
| Фано | 4.812876 |
| Хаффмана | 4.809089 |

Длина кода Гилберта-Мура ровно на 1 больше длины кода Шеннона
(`L = ⌈−log2 p⌉ + 1`), избыточность 1.598 < 2 — выполняется граница
пособия `Lср < H + 2`. Код префиксный и лексикографически упорядочен
(алфавитный).

Задание 4 — кодирование первых 100 символов:

- длина закодированной последовательности: **685 бит** (6.85 бит/символ);
- при равномерном коде (6 бит/символ): 600 бит → коэффициент 0.876
  (код длиннее равномерного — следствие высокой избыточности);
- в UTF-8 (16 бит/символ): 1600 бит → коэффициент сжатия **2.336**.

## Проверка по примеру из пособия (Таблица 13)

При вероятностях 0.36, 0.18, 0.18, 0.12, 0.09, 0.07 программа даёт
длины 3, 4, 4, 5, 5, 5 и среднюю длину **3.920000** — точно как в
пособии (Lср = 3.92, энтропия 2.37, граница 3.92 < 2.37 + 2).
