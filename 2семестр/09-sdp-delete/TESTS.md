# Тест: удаление из СДП

Тест из 32 вопросов: сначала базовые, затем сложные. Выберите один вариант в каждом вопросе. Ответы — внизу, в разделе «Ответы» (раскройте его).


## Уровень 1 — базовый

**1. Какой первый шаг алгоритма удаления вершины из СДП?**

- а) Удалить корень
- б) Найти вершину с ключом X
- в) Отсортировать дерево
- г) Вставить X

**2. Что делается, если найденная вершина имеет не более одного поддерева?**

- а) Ничего
- б) Вершину просто удаляем
- в) Ищем наибольшую вершину
- г) Делаем балансировку

**3. Какой указатель меняется при удалении вершины q без левого потомка?**

- а) *p := q→Left
- б) *p := q→Right
- в) *p := NIL
- г) q := NIL

**4. Какая вершина ставится на место удаляемой при двух поддеревьях?**

- а) Корень
- б) Самая правая вершина левого поддерева (наибольшая в левом)
- в) Самая левая вершина правого
- г) Любой лист

**5. Что эквивалентно «наибольшей вершине левого поддерева»?**

- а) Самая левая вершина левого
- б) Самая правая вершина левого поддерева, без правого потомка
- в) Корень левого
- г) Лист правого

**6. Что освобождается командой dispose(q)?**

- а) Корень
- б) Память удаляемой вершины q
- в) Все дерево
- г) Только указатель p


## Уровень 2 — средний

**7. Какая команда выполняется первой при замене вершины с двумя поддеревьями?**

- а) r→Right := q→Right
- б) s→Right := r→Left
- в) *p := r
- г) dispose(q)

**8. Что делает шаг 2) r→Left := q→Left?**

- а) Переносит левое поддерево удаляемой к r
- б) Удаляет r
- в) Меняет корень
- г) Создаёт новый лист

**9. Что делает шаг 3) r→Right := q→Right?**

- а) Переносит правое поддерево удаляемой вершины к r
- б) Удаляет правое
- в) Меняет s
- г) Сортирует

**10. Что делает шаг 4) *p := r?**

- а) Ставит r на место удаляемой вершины q
- б) Удаляет корень
- в) Делает r листом
- г) Ничего

**11. Как ищется самая правая вершина левого поддерева?**

- а) Циклом DO (r→Right ≠ NIL) s := r, r := r→Right
- б) Рекурсией по левым ссылкам
- в) Сортировкой
- г) Хешированием

**12. Что такое переменная s при поиске в левом поддереве?**

- а) Предыдущая вершина на пути к r
- б) Корень
- в) Лист
- г) Новый ключ

**13. Какая трудоёмкость удаления из СДП (по пособию)?**

- а) O(1)
- б) Такая же, как у добавления: O(log n) при n→∞
- в) O(n²)
- г) O(n log n)

**14. Что верно о случае, когда левый потомок удаляемой вершины не имеет правого поддерева?**

- а) Ошибка
- б) r = q→Left, и r становится новым корнем поддерева
- в) Дерево разрушается
- г) Нужен поиск по хешу

**15. Почему важна проверка «если s ≠ q» в программе sdp_delete.cpp?**

- а) Для скорости
- б) Без неё при s = q шаги 1) и 2) дали бы r→Left = r (цикл)
- в) Чтобы не удалять лист
- г) Чтобы сортировать

**16. Что произойдёт при удалении ключа, которого нет в дереве?**

- а) Удалится корень
- б) Дерево не меняется
- в) Дерево станет пустым
- г) Вставится ключ

**17. Какие ключи остаются после удаления ключа из дерева поиска по правилам пособия?**

- а) Все, кроме удалённого, в порядке возрастания при обходе слева направо
- б) Все ключи, включая удалённый
- в) Только корень
- г) Только листья

**18. Сохраняется ли свойство дерева поиска после удаления по пособию?**

- а) Нет
- б) Да: правило замены (наибольший из левого) сохраняет порядок ключей
- в) Только для листьев
- г) Только для корня


## Уровень 3 — сложный

**19. Почему наибольший элемент левого поддерева подходит на место удаляемого?**

- а) Он больше всех
- б) Он больше всех в левом поддереве, но меньше удаляемого и всех в правом
- в) Он равен удаляемому
- г) Он всегда лист

**20. Какой ключ станет корнем после удаления корня с двумя поддеревьями (если это правило)?**

- а) Наибольший из левого поддерева
- б) Наименьший из правого поддерева
- в) Случайный
- г) Новый ключ

**21. Допустим у удаляемой вершины q левое поддерево = 3 с правым 4. Какой будет r?**

- а) 3
- б) 4
- в) q
- г) NIL

**22. Для дерева q(5; L=3(R=4); R=8) после удаления q новый корень:**

- а) 3
- б) 4
- в) 8
- г) 5

**23. Что меняется в шаге 1) s→Right := r→Left при s = 3 и r = 4 (r без левого потомка)?**

- а) 3→Right становится NIL
- б) 3→Right становится 8
- в) Ничего не меняется
- г) Удаляется 4

**24. Почему на шаге 1) используется r→Left, а не r→Right?**

- а) r→Right равен NIL по выходу из цикла
- б) Так удобнее
- в) Это опечатка
- г) Нужен левый потомок для замены

**25. Что произойдёт, если не выполнить шаг 2) при s = q?**

- а) Ничего
- б) Вершина r станет собственным левым потомком — цикл
- в) Дерево станет ИСДП
- г) Корень удалится

**26. Чем отличается удаление из СДП от удаления из АВЛ по пособию?**

- а) Ничем
- б) В АВЛ после удаления выполняется балансировка поворотами
- в) В СДП балансировка обязательна
- г) В АВЛ нет замены

**27. Может ли после удаления СДП стать вырожденным?**

- а) Да, структура не балансируется
- б) Нет никогда
- в) Только при удалении корня
- г) Только для ИСДП

**28. Сколько всего шагов присваивания указателей в замене двух поддеревьев по пособию?**

- а) 1
- б) 4 (шаги 1)–4)) плюс освобождение памяти
- в) 2
- г) Ни одного

**29. Какой алгоритм по пособию ищет вершину с ключом X при удалении?**

- а) Поиск как в дереве поиска с указателем на указатель p
- б) Обход в ширину
- в) Хеш-поиск
- г) Линейный поиск

**30. Что хранит переменная q в алгоритме удаления?**

- а) Удаляемую вершину (q := *p)
- б) Корень
- в) Новый ключ
- г) Счётчик

**31. Почему трудоёмкость удаления равна трудоёмкости добавления?**

- а) Совпадение
- б) Оба состоят из конечного числа сравнений и присваиваний на шагах поиска (п. 11.3)
- в) Потому что оба используют корень
- г) Потому что оба O(1)

**32. Что вернёт поиск в дереве поиска по ключу, который был удалён?**

- а) Удалённую вершину
- б) NIL (вершины нет)
- в) Корень
- г) Ключ
