| `sdp_delete.cpp` | построение СДП, удаление вершины по ключу, обход слева направо после каждого удаления |
| `delete_sdp_explained.html` | пояснение алгоритма удаления из СДП (открывается в браузере) |

**Сборка и запуск:**

```bash
g++ -std=c++11 -Wall -o sdp_delete sdp_delete.cpp && ./sdp_delete
```

## Что делает программа

В меню выбирается источник данных:

- `1` — СДП из букв ФИО;
- `2` — СДП из неповторяющихся случайных чисел от 1 до 100 (количество задаётся пользователем, от 1 до 100).

Затем 10 раз запрашивается вершина для удаления. Удаление: если у вершины нет одного из поддеревьев, её заменяет другое; иначе вершина заменяется самой правой вершиной левого поддерева (предшественником). После каждого удаления выводится обход слева направо. Если ключа в дереве нет, программа сообщает об этом.

## 🧩 Как скомпилировать каждый файл

Команды для каждого исходника. Имя исполняемого файла совпадает с именем исходника.

### `sdp_delete.cpp`

Библиотеки не нужны, только компилятор.

**macOS** (clang):

```bash
clang++ -std=c++17 -Wall -o sdp_delete sdp_delete.cpp && ./sdp_delete
```

**Linux** (gcc / g++):

```bash
g++ -std=c++17 -Wall -o sdp_delete sdp_delete.cpp && ./sdp_delete
```

**Windows** (MinGW-w64, в терминале MSYS2 или PowerShell с g++ в PATH):

```bash
g++ -std=c++17 -Wall -o sdp_delete.exe sdp_delete.cpp
```
