# Вопросы по теме «Удаление из СДП»

Алгоритм удаления вершины из случайного дерева поиска.

Ответы даны строго по пособию «Структуры и алгоритмы обработки данных»; в скобках указан пункт и страница.

### 1. Какой первый шаг алгоритма удаления вершины из СДП?

Сначала нужно найти вершину с ключом, равным X.

> 📖 п. 11.3, с. 49

### 2. Как удаляется вершина, не имеющая поддеревьев?

Вершина не имеет поддеревьев — её просто удаляем: в алгоритме *p := q→Right при q→Left = NIL (здесь q→Right = NIL), после чего dispose(q).

> 📖 п. 11.3, с. 49–50

### 3. Как удаляется вершина, имеющая одно поддерево?

Если найденная вершина имеет не более одного поддерева, её просто удаляем: при q→Left = NIL указатель *p := q→Right, при q→Right = NIL — *p := q→Left.

> 📖 п. 11.3, с. 49–50

### 4. Как удаляется вершина, имеющая два поддерева? (сформулируйте правило удаления)

На место удаляемой вершины ставится наибольшая вершина из левого поддерева (наименьшая из правого), то есть самая правая вершина левого поддерева, которая не имеет правого поддерева.

> 📖 п. 11.3, с. 49

### 5. Как реализуется удаление, если в левом поддереве удаляемой вершины нет правого поддерева?

Тогда цикл поиска DO (r→Right ≠ NIL) не выполняется: r = q→Left, s = q. По пособию шаги 1) и 2) выполняются всегда; при s = q это дало бы r→Left = r. Поэтому в программе (sdp_delete.cpp) шаги 1) и 2) выполняются только при s ≠ q. Шаги 3) и 4) выполняются в обоих случаях.

> 📖 п. 11.3, с. 50

### 6. Как в алгоритме удаления достигается вершина, самая правая в левом поддереве удаляемой вершины?

Циклом: r := q→Left, s := q; DO (r→Right ≠ NIL) s := r, r := r→Right OD — то есть идём по правым ссылкам левого поддерева, пока они есть.

> 📖 п. 11.3, с. 50

### 7. Какие команды осуществляют замену удаляемой вершины?

1) s→Right := r→Left; 2) r→Left := q→Left; 3) r→Right := q→Right; 4) *p := r; затем dispose(q).

> 📖 п. 11.3, с. 50–51

### 8. Какова трудоемкость удаления вершины из СДП?

Складывается из конечного числа сравнений и присваиваний на каждом шаге поиска; трудоёмкость такая же, как у добавления в СДП: O(log n) при n→∞.

> 📖 п. 11.3, с. 51
