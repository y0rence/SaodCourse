## О курсовой

Программа на C++ работает с базой данных сотрудников (`testBase2.dat`, формат CP866):
чтение файла, кодировки, сортировка методом Хоара, четыре вида поиска, построение
двоичного дерева поиска (ДБД) по ФИО и кодирование файла кодом Шеннона
(вариант 74, метод E=2).

Всё меню — интерактивное, в консоли: просмотр базы постранично, сортировка,
поиск по дате рождения / ФИО / должности / отделу, дерево поиска и пункт
**8 — кодирование базы кодом Шеннона**: таблица кода (символ, вероятность,
кодовое слово, длина), проверка неравенства Крафта, сравнение средней длины
кода с энтропией файла, избыточность, запись упакованной базы в
`testBase2.shannon` и коэффициент сжатия.

## Что в программе

| Раздел | Функции |
|---|---|
| **Чтение файла** | загрузка `testBase2.dat`, проверка формата записи |
| **Кодировка** | преобразование CP866 ↔ UTF-8 через `iconv` |
| **Сравнение / ключи** | `cmp_workers` — сортировка по нескольким ключам (дата → фамилия → имя) |
| **Сортировка** | `quick_sort_hoare` — метод Хоара по указателям на записи |
| **Вывод** | постраничный просмотр (`PAGE_SIZE = 20`) с выравниванием колонок |
| **Очередь** | очередь результатов поиска (`queue_push`, `queue_count`, `queue_free`) |
| **Поиск** | по дате рождения (год / месяц+год / день+месяц+год), по ФИО, по должности, по номеру отдела |
| **ДБД** | двоичное дерево по ФИО: вставка, обход, размер, высота, контрольная сумма, поиск по дереву |

## Сборка и запуск

**macOS / Linux** (нужна библиотека `iconv`, входит в стандартную библиотеку glibc):

```bash
cd myproject
clang++ -std=c++17 main.cpp -o app -liconv && ./app
```

или

```bash
g++ -std=c++17 main.cpp -o app && ./app
```

**Windows** (в WSL или MinGW с доступом к файлам CP866):

```bash
g++ -std=c++17 main.cpp -o app.exe && ./app.exe
```

Программа читает `testBase2.dat` из текущей каталога — запускать нужно из папки `myproject`.
