Весь файл main.cpp (и db.h) делится на 7 смысловых групп. Вот что входит в каждую, одной строкой:

main main склеивает всё вместе: один раз читает файл (группа ЧТЕНИЕ), показывает меню, по выбору вызывает сортировку, просмотр или нужный поиск.

Группа 1: ЧТЕНИЕ ФАЙЛА

Эти функции — единственное место программы, которое открывает файл на диске и читает из него байты. Сортировка, поиск и вывод уже работают только с памятью, с файлом больше никогда не взаимодействуют.

rtrim файл

void rtrim(char *s) {
  int len = (int)strlen(s);
  while (len > 0 && s[len - 1] == ' ')
    len--;
  s[len] = '\0';
}
СтрокаЧто делает
int len = strlen(s)узнаём текущую длину строки
while (len > 0 && ...)пока строка не пустая и последний символ — пробел
len--«укорачиваем» длину на 1
s[len] = '\0'ставим конец строки в новое место — пробелы справа обрезаны

Используется сразу после чтения каждого текстового поля из файла — убирает пробелы-заполнители, которыми в базе выровнены все поля до фиксированной ширины.

load_database файл

Worker *load_database(const char *filename, int *count) {
  FILE *f = fopen(filename, "rb");
  if (f == NULL) { *count = 0; return NULL; }

  fseek(f, 0, SEEK_END);
  long size = ftell(f);
  fseek(f, 0, SEEK_SET);

  int record_size = FIO_LEN + sizeof(short) + POS_LEN + BIRTH_LEN;
  int n = size / record_size;

  Worker *db = (Worker *)malloc(n * sizeof(Worker));

  for (i = 0; i < n; i++) {
    fread(db[i].fio, 1, FIO_LEN, f);
    db[i].fio[FIO_LEN] = '\0';

    fread(&db[i].dept, sizeof(short), 1, f);

    fread(db[i].position, 1, POS_LEN, f);
    db[i].position[POS_LEN] = '\0';

    fread(db[i].birth, 1, BIRTH_LEN, f);
    db[i].birth[BIRTH_LEN] = '\0';

    rtrim(db[i].fio);
    rtrim(db[i].position);
  }

  fclose(f);
  *count = n;
  return db;
}
СтрокаЧто делает
fopen(filename, "rb")открываем файл; "rb" — read binary, как бинарный, а не текстовый
if (f == NULL) ...файл не открылся — сообщаем через *count=0 и возвращаем NULL
fseek(f,0,SEEK_END)перематываем указатель чтения в конец файла
size = ftell(f)спрашиваем текущую позицию — это и есть размер файла в байтах
fseek(f,0,SEEK_SET)перематываем обратно в начало
record_size = ...размер одной записи: 30+2+22+10 = 64 байта
n = size / record_sizeсколько записей в файле: 256000/64 = 4000
malloc(n * sizeof(Worker))выделяем в динамической памяти массив из n структур Worker
fread(db[i].fio, 1, FIO_LEN, f)читаем 30 байт прямо в поле fio текущей записи
db[i].fio[FIO_LEN]='\0'в файле после этих 30 байт нет завершающего нуля — дописываем сами
fread(&db[i].dept, sizeof(short), 1, f)номер отдела — готовое число (2 байта), без '\0'
fread(db[i].position,...) + '\0'то же, что с fio, для должности
fread(db[i].birth,...) + '\0'то же для даты рождения
rtrim(db[i].fio) / rtrim(db[i].position)убираем пробелы-заполнители справа
fclose(f)файл прочитан целиком, закрываем
*count = n; return dbвозвращаем количество записей через count и указатель на весь массив
Это единственная функция во всей программе, где встречаются fopen/fread/fclose. Дальше весь код работает с уже загруженным в память массивом db — ни сортировка, ни поиск к файлу больше не обращаются.

Группа 2: КОДИРОВКА (CP866 ↔ UTF-8)

Эти функции не читают файл и не сравнивают данные — они только переводят текст между двумя разными представлениями кириллицы. База хранит текст в CP866 (1 буква = 1 байт, старая кодировка DOS), а терминал на маке показывает и принимает текст в UTF-8 (1 кириллическая буква = 2 байта).

cp866_to_utf8 кодировка

void cp866_to_utf8(const char *src, char *dst, int dst_size) {
  iconv_t cd = iconv_open("UTF-8", "CP866");

  size_t inbytesleft = strlen(src);
  size_t outbytesleft = dst_size - 1;
  char *inbuf = (char *)src;
  char *outbuf = dst;

  iconv(cd, &inbuf, &inbytesleft, &outbuf, &outbytesleft);
  *outbuf = '\0';

  iconv_close(cd);
}
СтрокаЧто делает
src, dst, dst_sizesrc — исходный текст в CP866; dst/dst_size — куда и сколько места под результат
iconv_open("UTF-8","CP866")«настраиваем переводчик»: переводим ИЗ CP866 В UTF-8
inbytesleft = strlen(src)сколько байт ещё осталось прочитать из src
outbytesleft = dst_size - 1сколько места осталось в dst (минус 1 — под завершающий '\0')
inbuf, outbufрабочие указатели — iconv двигает их сама по мере перевода
iconv(cd, &inbuf, ...)сам перевод: читает из inbuf, пишет в outbuf
*outbuf = '\0'outbuf теперь указывает сразу за последним записанным байтом — там ставим конец строки
iconv_close(cd)«закрываем переводчик»

Кто вызывает: только функции группы ВЫВОД (print_worker) — перед тем, как напечатать ФИО и должность на экране.

utf8_to_cp866 кодировка

Устроена так же, как cp866_to_utf8, только наоборот — iconv_open("CP866", "UTF-8").

Кто вызывает: функции группы ПОИСК, которые принимают текстовый ввод от человека (search_by_fio, search_by_position) — то, что набрали в терминале (UTF-8), нужно перевести в CP866 перед сравнением с базой.

Группа 3: СРАВНЕНИЕ / КЛЮЧИ

Эти функции ничего не читают из файла, никуда не выводят и сами не сортируют — они просто отвечают на вопрос «что меньше?» или «встречается ли это здесь?». Их вызывают СОРТИРОВКА (cmp_workers) и ПОИСК (my_strstr, get_year и другие).

get_day / get_month / get_year ключи

int get_day(const char *birth)   { return (birth[0]-'0')*10 + (birth[1]-'0'); }
int get_month(const char *birth) { return (birth[3]-'0')*10 + (birth[4]-'0'); }
int get_year(const char *birth)  { return (birth[6]-'0')*10 + (birth[7]-'0'); }

Дата хранится как текст «дд-мм-гг» (индексы 0-1 — день, 3-4 — месяц, 6-7 — год). символ - '0' превращает цифру-символ в цифру-число. Первая цифра поля — десятки, вторая — единицы.

Кто вызывает: cmp_workers (для сортировки), binary_search_year и search_by_date (для поиска).

cmp_workers ключи

int cmp_workers(Worker *a, Worker *b) {
  int y1 = get_year(a->birth), y2 = get_year(b->birth);
  if (y1 != y2) return y1 - y2;

  int m1 = get_month(a->birth), m2 = get_month(b->birth);
  if (m1 != m2) return m1 - m2;

  int d1 = get_day(a->birth), d2 = get_day(b->birth);
  if (d1 != d2) return d1 - d2;

  return my_strcmp(a->fio, b->fio);
}
СтрокаЧто делает
y1, y2 = get_year(...)сравниваем года рождения
if (y1 != y2) return y1-y2года разные — этого достаточно (реализация ключа C=3)
m1, m2 = get_month(...)года совпали — сравниваем месяцы
if (m1 != m2) return m1-m2месяцы разные — хватит
d1, d2 = get_day(...)месяцы совпали — сравниваем дни
if (d1 != d2) return d1-d2дни разные — хватит
return my_strcmp(a->fio, b->fio)дата совпала у двух людей — сравниваем по ФИО, чтобы порядок был однозначным
Это и есть «правило сортировки». Сама функция ничего не переставляет — она только ОТВЕЧАЕТ на вопрос «кто из двух меньше». Переставляет указатели quick_sort_hoare (группа СОРТИРОВКА), вызывая cmp_workers на каждом шаге.

my_strcmp ключи

int my_strcmp(const char *a, const char *b) {
  int i = 0;
  while (a[i] != '\0' && b[i] != '\0') {
    if (a[i] != b[i]) return a[i] - b[i];
    i++;
  }
  return a[i] - b[i];
}

Своя версия strcmp (задание запрещает пользоваться готовой). Сравнивает символ за символом, возвращает отрицательное/0/положительное число. Используется в cmp_workers как последний критерий при равных датах.

my_strstr ключи

int my_strstr(const char *text, const char *pattern) {
  for (i = 0; text[i] != '\0'; i++) {
    j = 0;
    while (pattern[j] != '\0' && text[i + j] == pattern[j]) j++;
    if (pattern[j] == '\0') return i;
  }
  return -1;
}

Своя версия strstr — ищет pattern где угодно внутри text, возвращает позицию первого совпадения или -1. Для каждой стартовой позиции i пробует сопоставить pattern посимвольно; если дошли до конца pattern — совпадение найдено.

Кто вызывает: search_by_fio (ищет по ФИО) и search_by_position (ищет по должности) — оба текстовых поиска «по вхождению», это их общий строительный блок.

Группа 4: СОРТИРОВКА

Эта группа отвечает на требование S=2 методички. Она НЕ умеет сравнивать записи сама — для этого вызывает cmp_workers из группы СРАВНЕНИЕ. И она НЕ умеет читать файл — работает уже с готовым массивом указателей, который ей передали.

swap_ptr сортировка

void swap_ptr(Worker **a, Worker **b) {
  Worker *t = *a;
  *a = *b;
  *b = t;
}
СтрокаЧто делает
Worker *t = *aзапоминаем, на что указывал a
*a = *ba теперь указывает туда же, куда b
*b = tb теперь указывает туда, куда раньше указывал a

Параметры — Worker** (указатель на указатель), иначе функция поменяла бы местами свои локальные копии, а в массиве idx снаружи ничего бы не изменилось.

quick_sort_hoare сортировка

Псевдокод из методички «СиАОД» (стр. 24):

x:=aL, i:=L, j:=R DO (i<=j) DO (ai<x) i:=i+1 OD DO (aj>x) j:=j-1 OD IF (i<=j) ai<->aj, i:=i+1, j:=j-1 FI OD IF (L<j) <сортировка (L,j)> FI IF (i<R) <сортировка (i,R)> FI
void quick_sort_hoare(Worker **idx, int L, int R) {
  Worker *x = idx[(L + R) / 2];
  int i = L, j = R;

  do {
    while (cmp_workers(idx[i], x) < 0) i++;
    while (cmp_workers(idx[j], x) > 0) j--;

    if (i <= j) {
      swap_ptr(&idx[i], &idx[j]);
      i++;
      j--;
    }
  } while (i <= j);

  if (L < j) quick_sort_hoare(idx, L, j);
  if (i < R) quick_sort_hoare(idx, i, R);
}
СтрокаЧто делает
idx, L, Ridx — индексный массив указателей; L, R — границы участка (в первом вызове — весь массив)
x = idx[(L+R)/2]опорный элемент (pivot) — запись из середины участка
i = L, j = Rдва «бегунка»: i — от начала вправо, j — от конца влево
while (cmp_workers(idx[i],x)<0) i++двигаем i вправо, пока idx[i] «меньше» опорной
while (cmp_workers(idx[j],x)>0) j--двигаем j влево, пока idx[j] «больше» опорной
if (i<=j) { swap_ptr(...); i++; j--; }меняем местами указатели idx[i], idx[j], сдвигаем оба бегунка
} while (i <= j)повторяем, пока бегунки не пересекутся
if (L<j) quick_sort_hoare(idx,L,j)рекурсивно сортируем левую часть
if (i<R) quick_sort_hoare(idx,i,R)рекурсивно сортируем правую часть

Сортируются указатели idx[i] (Worker*), а не сами записи — требование S=2, «индексный массив указателей». Сравнение на каждом шаге делегируется в cmp_workers (группа СРАВНЕНИЕ) — сама функция не знает, что такое «дата рождения».

Группа 5: ВЫВОД НА ЭКРАН

Эта группа не знает, что такое база данных, очередь или поиск — она умеет только одно: красиво напечатать переданный ей массив указателей Worker** постранично. Именно поэтому её можно использовать и для всей базы, и для любого результата поиска.

utf8_len вывод

int utf8_len(const char *s) {
  int len = 0;
  for (i = 0; s[i] != '\0'; i++)
    if (((unsigned char)s[i] & 0xC0) != 0x80)
      len++;
  return len;
}

Считает количество настоящих символов в UTF-8 строке, а не байт. В UTF-8 байт-«продолжение» символа всегда начинается с битов 10xxxxxx (0x80 в старших двух битах); условие истинно только для байта, с которого НАЧИНАЕТСЯ символ. Без этого колонки таблицы съезжали бы, потому что одна кириллическая буква — это 2 байта.

print_padded вывод

void print_padded(const char *s, int width) {
  int len = utf8_len(s);
  printf("%s", s);
  for (i = len; i < width; i++) printf(" ");
}

Печатает строку, затем дописывает пробелы до width символов (используя utf8_len, а не байтовую длину) — так колонка выравнивается правильно независимо от того, кириллица там или латиница.

print_header вывод

Печатает шапку таблицы (названия колонок «#», «ФИО сотрудника», «Отд», «Должность», «Дата рожд.») и строку-разделитель из дефисов нужной ширины.

print_worker вывод

void print_worker(int num, Worker *w) {
  char fio_utf8[128];
  char pos_utf8[128];

  cp866_to_utf8(w->fio, fio_utf8, sizeof(fio_utf8));
  cp866_to_utf8(w->position, pos_utf8, sizeof(pos_utf8));

  printf("%3d | ", num);
  print_padded(fio_utf8, FIO_COL);
  printf(" | %4d | ", w->dept);
  print_padded(pos_utf8, POS_COL);
  printf(" | %s\n", w->birth);
}

void view_pages(Worker **idx, int n, const char *title, const char *key_info) {
  int pages = (n + PAGE_SIZE - 1) / PAGE_SIZE;
  int page = 0;

  while (1) {
    int start = page * PAGE_SIZE;
    int end = start + PAGE_SIZE;
    if (end > n) end = n;

    printf("\n%s\n", title);
    if (key_info[0] != '\0') printf("%s\n", key_info);
    print_header();

    if ((cmd == 'p' || cmd == 'P') && page > 0) page--;
  }
}

Группа 6: ОЧЕРЕДЬ

Задание требует: «из записей с одинаковым ключом формируется очередь, содержимое очереди выводится на экран». Эта группа — именно про структуру данных очередь (связный список Head/Tail по методичке) и про то, как её содержимое попадает на экран через группу ВЫВОД.

QueueNode / Queue / queue_init очередь

struct QueueNode {
  Worker *rec;
  QueueNode *next;

  QueueNode *tail;

СтрокаЧто делает

Структура по методичке «СиАОД» (стр. 28): новый элемент добавляется в конец (через tail) — в отличие от стека, где добавление и снятие идут с одного конца.

queue_push очередь

1) p->Next := NIL 2) IF (Head <> NIL) Tail->Next := p ELSE Head := p FI 3) Tail := p
void queue_push(Queue *q, Worker *rec) {
  QueueNode *p = (QueueNode *)malloc(sizeof(QueueNode));
  p->rec = rec;
  p->next = NULL;

  if (q->head != NULL)
    q->tail->next = p;
  else
    q->head = p;

  q->tail = p;
}
СтрокаЧто делает
p = malloc(sizeof(QueueNode))выделяем память под новый узел
p->rec = recсохраняем указатель на найденную запись
p->next = NULLшаг 1: новый узел пока последний
if (q->head != NULL) q->tail->next = pшаг 2 (IF): очередь не пуста — цепляем после текущего последнего
else q->head = pшаг 2 (ELSE): очередь была пуста — новый узел становится и первым
q->tail = pшаг 3: новый узел теперь последний

Кто вызывает: все пять функций группы ПОИСК — каждая, найдя подходящую запись, кладёт её в очередь этим вызовом.

queue_count очередь

int queue_count(Queue *q) {
  int count = 0;
  QueueNode *p = q->head;
  while (p != NULL) { count++; p = p->next; }
  return count;
}

Идёт по всем узлам и считает их — используется, чтобы узнать, сколько записей нашлось (и чтобы понять, пустая очередь или нет).

queue_free очередь

void queue_free(Queue *q) {
  QueueNode *p = q->head;
  while (p != NULL) {
    QueueNode *next = p->next;
    free(p);
    p = next;
  }
  q->head = NULL;
  q->tail = NULL;
}

Освобождает всю память очереди. Важно сначала сохранить p->next в next, а уже потом вызывать free(p) — после free(p) читать p->next нельзя (память уже отдана).

Очередь — связный список, по которому можно идти только вперёд; чтобы в view_pages можно было листать результат и вперёд, и назад (n/p), очередь один раз копируется в обычный массив. Добавлена эта функция, чтобы не повторять один и тот же код «сосчитать → проверить на пустоту → скопировать в массив → показать → освободить» в каждой из пяти функций поиска — теперь они вызывают её одной строкой.

Группа 7: ПОИСК

binary_search_year поиск

Псевдокод (методичка, стр. 37, версия 1):

Worker **binary_search_year(Worker **idx, int n, int year) {
  Worker **lo = idx;
  Worker **hi = idx + n - 1;

  while (lo <= hi) {
    Worker **mid = lo + (hi - lo) / 2;
    int y = get_year((*mid)->birth);

    if (y == year)
      return mid;

    if (y < year)
      lo = mid + 1;
    else
      hi = mid - 1;
  }

  return NULL;
}
СтрокаЧто делает
L = 0, R = n - 1границы участка поиска — сначала весь массив

if (y == year) return mнашли — какую-то одну подходящую запись

return -1участок сузился до пустого — такого года нет
Работает БЫСТРО (логарифм от n), но только потому, что база отсортирована именно по году (требование C=3). Поэтому используется только в search_by_date — для поиска по должности, отделу и ФИО такой приём не годится: база по ним не отсортирована.

void tree_find_year(TNode *p, int year, Queue *q) {
  if (p == NULL) return;
  int y = get_year(p->rec->birth);
  if (y > year) { tree_find_year(p->Left, year, q); return; }   // правее все годы больше искомого

  tree_find_year(p->Left, year, q);
  queue_push(q, p->rec);
  tree_find_year(p->Right, year, q);
}

Найденные записи попадают в очередь в порядке обхода, затем показываются через show_queue_result.

Характеристики дерева (tree_stats, tree_print_report)

Обход складывает размер, сумму лет, максимальную глубину и сумму глубин. Глубина корня равна 1. Средняя высота = сумма глубин / размер.

Как собрать и запустить

clang++ main.cpp -o app -liconv
./app

Флаг -liconv обязателен — функции iconv_open/iconv/iconv_close (группа КОДИРОВКА) лежат в отдельной библиотеке, а не в стандартной stdio.
