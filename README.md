## О проекте

Это репозиторий со всеми лабораторными работами по дисциплине **«Структуры и алгоритмы обработки данных» (СиАОД)**. Работы выполнены по псевдокоду из пособия Е. В. Кураповой и Е. П. Мачикиной «Структуры и алгоритмы обработки данных» (СибГУТИ).

Программы написаны на C и C++. Для каждой работы есть:

- **README** с заданием, файлами, командами сборки и результатами;
- **THEORY.md** с теорией (для работ с деревьями);
- исходный код без комментариев, отформатированный по единому `.clang-format`.

## Семестры

| Раздел | Что внутри | Работ | Открыть |
|---|---|---|---|
| **1 семестр** | Сортировки, поиск, линейные списки, хеширование | 15 | [1семестр/README.md](1семестр/README.md) |
| **2 семестр** | Деревья: ДОП, A1 и A2, ИСДП, АВЛ, СДП, удаление из деревьев, поиск подстроки, код Шеннона | 11 | [2семестр/README.md](2семестр/README.md) |

Сайт-витрина проекта: [index.html](index.html). Откройте файл в браузере.

У каждой работы есть **интерактивная страница** `lab.html` рядом с README:
пошаговый проигрыватель алгоритма, карточка-задание и «листочек» с кодом,
в котором подсвечивается текущая строка — псевдокод или настоящий исходник
на выбор. Формат страниц описан в [docs/lab-pages.md](docs/lab-pages.md).

## Как вносить изменения

Отдельная ветка на задачу, pull request даже для небольших улучшений,
обязательные проверки перед слиянием — см. [CONTRIBUTING.md](CONTRIBUTING.md).
Автоматически проверки запускает CI: [.github/workflows/checks.yml](.github/workflows/checks.yml).

## Как запустить

Подробная установка компиляторов и SFML для Windows, macOS и Linux — [INSTALL.html](INSTALL.html) (текстовая версия: [INSTALL.md](INSTALL.md)).

Программы компилируются любым компилятором C или C++ (`gcc`, `g++`, `clang`). Программы с графиками из 1 семестра используют **SFML 3** / **CSFML**. Точные команды — в README каждой папки.
